# A04 — Figures and write-up from stored results

## Goal

Every figure in spec §7 and §7b, the executed notebook and a complete
RESULT.md, rendered **only** from results stored by A01–A03. Nothing
is refit.

## Inputs and binding notes (Claude, review A03)

* All inputs are on disk from A01–A03; check sha256 against their
  reports before rendering.
* Median |λ| differs ~150× between tissues (lung ~320, marrow ~2), so
  `aging_vectors` uses **log** axes and facets or styles by tissue.
* RESULT.md §5: the header verbatim from A03. RESULT.md §7 Limits: copy
  the bullets under "Limits to copy verbatim" in
  `~/Documents/scJDO2/coord/aging/reviews/A03.md`. Add nothing
  interpretive beyond them.
* `lambda_ratio_soft_axis` for non-basin types is unstable; in
  `compare_summary`, show it only for types with young holder fraction
  ≥ 0.5 and print "—" otherwise, with a footnote.
* `energy_transect`: render for the 3 basin types (lung fibroblast,
  lung NK, marrow granulocyte), neighbour = nearest other eligible
  centroid in the same tissue.

## Steps

1. New plotting functions in `scjdo2/plot/figures_v05.py`, each with a
   synthetic unit test in `tests/test_aging_figures.py` committed
   before it is used on real data:
   `aging_vectors`, the `groups=` extension of `spectrum_ladder`, the
   displacement-arrow extension of `soft_axis_map`, and
   `energy_transect` (the adapter exposes `EnergyDriftAdapter.energy`,
   so this one is not skipped).
2. `scripts/render_aging_figures.py` → §7 and §7b, PDF + PNG at
   200 dpi, footer as spec.
3. `scripts/make_aging_notebook.py` → `notebooks/aging_basins.ipynb`,
   executed in place.
4. RESULT.md complete to §8; §6 lists every figure by path.
5. `benchmarks/figures/aging/MANIFEST.csv`
   (`path, spec_item, tissue, age, source_files`).
