# A02 — Shared reference space and drift fits

## Goal

Per tissue: reference (young), scArches-mapped shared space (both
ages), standalone old; then three energy-drift fits (shared,
standalone young, standalone old) with per-cell `basin_index`.

## Steps

1. §3 — write `scripts/fit_tms_scvi.py` exactly as spec §3. If the
   A01 artifacts are gone, regenerate them with the commands in the
   A01 report first and check sha256 matches; a mismatch is a
   deviation to report, not a stop.
2. **Frozen-reference check.** After query training, compute the max
   absolute change of every reference parameter that scArches is
   supposed to freeze (encoder/decoder weights other than the new
   batch-embedding rows). Report it as
   `{tissue}_ref_weights_max_abs_change`. It must be 0.
3. §4 — write `scripts/fit_tms_drift.py` exactly as spec §4 (library
   code at its current version, parameters unchanged), then
   `classify_basin_latent(rule="lead_eig")`.
4. Commit per-type summaries (CSV), not the h5ad:
   `benchmarks/aging/qc/{tissue}_scvi_metrics.csv`
   (`fit, epochs_run, best_val_elbo, mapping_path`),
   `benchmarks/aging/qc/{tissue}_drift_metrics.csv`
   (`fit, final_loss, sym_median, sym_max`),
   `benchmarks/aging/qc/{tissue}_basin_fraction.csv`
   (`fit, cell_type, age_group, n, basin_fraction`).
5. RESULT.md §3 Mapping path.

## Gate

* `{tissue}_ref_weights_max_abs_change == 0` for both tissues.
  Otherwise blocked: the shared space is not a frozen reference.
* Symmetry: `sym_max` recorded for every fit; above 1e-4 is blocked
  (implementation check; spec expects ~1e-6).
* CPU-only runs use `max_epochs=200` and say so.
