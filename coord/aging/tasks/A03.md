# A03 — Run the pre-registered tests

## Goal

The per-type tables, the aging modes and the §6 outcome header. This
is the task where the result is decided, so it runs once, with the
seeds and parameters in the spec, and nothing is rerun to change a
number.

## Inputs (from aging/A02, on disk in your folder)

`benchmarks/aging/{tissue}_shared.h5ad` (per-cell `J_latent` in
`uns["scjdo2"]`, `X_scVI_shared`, basin calls) and
`{tissue}_standalone_{young,old}.h5ad`; sha256 in
`coord/aging/reports/A02.json`, check before use.

## Clarifications (binding; Claude, review A02)

1. **The §4b isotropy and §5 anticipation tests run in the shared space
   only** (`use_rep="X_scVI_shared"`, `n_cells_centroid=30`,
   `min_cells=200`, `n_null=1000`, `seed=0`). Standalone young and old
   latents are unrelated coordinate systems: direction matching and the
   displacement `d` are undefined across them. PREREG §4b's null is
   defined on "the fixed shared-space drift".
2. **`{tissue}_compare_standalone.csv`** holds axis-free per-type,
   per-age quantities only, one row per `(cell_type, age_group)`:
   `cell_type, age_group, n, lead_eig, median_abs_lambda, anisotropy,
   basin_fraction, spectrum` (sorted eigenvalues of the centroid
   operator, `;`-joined), from each standalone fit; plus the same
   columns from the shared fit for side-by-side reading.
3. **Column definitions** (centroid operator = `compare.centroid_operator`
   on that type × age's cells, 30 cells):
   * `lead_eig` = largest real eigenvalue; `soft axis` = its eigenvector;
   * `median_abs_lambda` = median of |eigenvalues|;
   * `anisotropy` = `median_abs_lambda / |lead_eig|` (larger = one
     direction much softer than the rest);
   * `lambda_ratio_soft_axis` = old eigenvalue matched (by
     `match_directions`) to the young soft axis ÷ young `lead_eig`;
   * `basin_fraction` = fraction of the type × age's cells classified
     `holder` by the locked rule in that fit.
4. **`substate_alignment`**: the census `obs` has no sub-state
   annotation below `cell_type`, so it is `NaN` for every type with the
   deviation stated once. Do not derive sub-states by clustering.
5. **`correction_artifact`** (PREREG §3): True iff for either age group
   `basin_fraction ≥ 0.5` in the shared fit and `< 0.5` in that age's
   standalone fit, or vice versa.

## Steps

1. §5 — write `scripts/run_tms_compare.py`; call `compare_types` as in
   the spec on the shared space and on the standalone fits.
2. Flag `correction_artifact` per PREREG §3. Add the column to every
   compare CSV.
3. `compare_pooled.csv` must have, at least, columns `tissue,
   cell_type, correction_artifact, iso_pass, ant_pass, S,
   iso_null_q95, cos_abs_u_young_d, ant_null_q95`.
4. `aging_modes` as spec §5 → `benchmarks/aging/aging_modes.csv`
   (`tissue, cell_type, mode_id, mode_label, silhouette_k`).
   If `scjdo2/compare.py` lacks a helper, add `aging_modes(...)`
   **additively** with a synthetic unit test in
   `tests/test_compare_aging.py`. Do not change `isotropy_test`,
   `anticipation_test` or `IsotropyResult`.
5. §6 — compute majorities (non-artifact eligible types, pooled and
   per tissue) and write the matching header verbatim in RESULT.md §5.
   Fill RESULT.md §4, §4b.
6. Before reporting, run
   `python scripts/aging_outcome_check.py` (reads your working tree) and confirm it agrees.
