# A01 — Environment, data, preprocessing

## Goal

A reproducible environment and, per tissue (lung, marrow), a
downsampled, HVG-annotated AnnData that A02 can fit on. Nothing is
fitted in this task.

## Already done (A00, commit 20f1371) — do not redo

Spec §0.2 and §0.3 are implemented and committed by Claude: PREREG
§2a and §4b, the §4b statistic in `scjdo2/compare.py`, and its tests.
Do not edit `scjdo2/compare.py`, the tests or PREREG in this task.

## Steps

1. §0.1 — build the environment and run
   `python -m pytest tests/test_compare_aging.py tests/test_measured_flow_figures.py -q`.
   Also run the full suite `python -m pytest tests -q` and record the
   counts. Locally, 6 tests in `tests/test_opspace_pitchfork.py` fail
   only because the v1 `scjdo` package is not installed; if they fail
   for that reason in your environment too, report it and continue.
   Any failure in `tests/test_compare_aging.py` is a stop.
   Write `benchmarks/aging/ENV.md` (Python, torch, scvi-tools, scanpy,
   cellxgene-census, scarches versions; CPU/GPU model; RAM; disk;
   whether this sandbox persists across sessions).
2. §1 — run `python scripts/fetch_tms_aging.py` unmodified. If it fails,
   stop (blocked) with the traceback; do not patch it.
3. §2 — write `scripts/preprocess_tms_aging.py` exactly as spec §2,
   applying the §2a rule now in `PREREG_aging_basins.md`.
   CLI: `--tissue {lung,marrow} --seed 0`.
4. Write QC tables (CSV, committed):
   * `benchmarks/aging/qc/{tissue}_donor_type_counts_before.csv`
   * `benchmarks/aging/qc/{tissue}_donor_type_counts_after.csv`
   * `benchmarks/aging/qc/{tissue}_eligible_types.csv`
     (`cell_type, n_young, n_old, eligible`)
5. Start `benchmarks/aging/RESULT.md` with §1 Data and §2a only.

## Gate (feasibility, not a prereg statistic)

* All unit tests pass. Otherwise blocked.
* Each tissue has ≥ 1 eligible type (≥ 200 cells per age after
  downsampling). A tissue with 0 is reported, not rescued.

## Stop and ask

Census version or dataset IDs differ from PREREG §1; any age label not
in the script's young/old sets is ≥ 5 % of cells; compute > budget.
