# aging/X06 — Fixed-axis curvature statistic on mouse basins (EXPLORATORY)

**Exploratory; statistic designed after the frozen results.** Nothing
here changes A03 or RESULT.md. First line of the report and
`RESULT_X06.md`: "EXPLORATORY — statistic designed after the frozen
result". No model is fitted.

## Question

Does the curvature along the young soft axis, relative to overall
stiffness, differ between old and young mice in the three mouse types
that are real basins (lung fibroblast, lung NK, marrow granulocyte),
where the soft axes are clearly stable? Test:
`compare.softaxis_curvature_trend` with `ages` = 1 for old, 0 for young
(a donor-level two-group test; permutations relabel mice).

## Inputs (check sha256 against A02/X04)

`benchmarks/aging/{lung,marrow}_shared.h5ad` (scVI seed 0) and the X04
shared-space seeds 1, 2 (`benchmarks/aging/x04/{tissue}_shared_s{1,2}.h5ad`).

## Steps (`scripts/x06_softaxis_mouse.py`; seed 0)

1. Per type and shared-space seed: mice with **≥ 30** cells of the type
   contribute; `n_common` = smallest such count; donor operators
   `compare.donor_operator(z, J, n_common, n_draws=100,
   n_cells_centroid=30, seed=crc32(f"{type}|{mouse}"))`; reference
   operator = `centroid_operator` (30 cells) on the pooled young cells.
   Expected contributors (from A01 QC): lung fibroblast 2 young / 5 old
   (`n_common` 36); lung NK 4 / 5 (35); marrow granulocyte 2 / 10 (70).
   Report the number of distinct labellings for each type (C(n, n_young))
   and the smallest attainable p (lung fibroblast ≈ 0.048: it can pass
   only at the extreme).
2. **Real data:** `softaxis_curvature_trend(..., n_perm=1000, seed=0)`
   per type × seed. → `benchmarks/aging/x06/real.csv`
   (`seed, tissue, cell_type, n_young, n_old, n_common, n_labellings,
   slope, p, passes, ref_soft_eigenvalue`).
3. **Power by injection** (seed 0 space only): single-axis softening of
   the **old** mice's cells, `J' = J + (F^(−1) − 1)(uᵀJu) u uᵀ` for old
   cells only, `F ∈ {1.25, 1.5, 2, 3, 5}`; and uniform `J' = J / 2` on
   old cells (specificity). Pass = `passes`. →
   `benchmarks/aging/x06/power.csv`.
4. **Reading rule (fixed before step 2):** a type shows **soft-axis
   change with age** if `p ≤ 0.05` in seed 0 **and** in at least one of
   seeds 1, 2, with the same sign of slope. Report `MDE` = smallest F
   that passes in step 3 (`> max` if none), and whether uniform ×2
   passes (it should not). Write `x06_verdict` per type to
   `benchmarks/aging/x06/summary.csv`.
5. `benchmarks/aging/x06/RESULT_X06.md`: first line as above, what ran,
   the rule verbatim, tables. No other interpretation.
