## Required changes (rendering only; no refit, no new statistics)
1. **Saddle marker in `energy_transect`.** In the lung fibroblast
   transect the curve has a clear interior maximum near x ≈ 0.74, but
   the "intervening saddle" triangle is drawn at x = 0 on the young
   floor. In the granulocyte transect there is no interior maximum and
   the triangle is again at x = 0. Rule: the saddle is the highest point
   of the stored E(z) curve strictly between the two floors' positions
   on the transect, and only if it is a local maximum (higher than
   both neighbours on the grid). If there is none, draw no triangle and
   annotate "no barrier along this transect". Report the barrier height
   (E_saddle − E_young floor) in the annotation box when it exists. Add
   a unit test: a synthetic double-well curve puts the saddle at the
   interior maximum; a monotone curve yields no saddle.
2. **`aging_vectors` axis ranges.** The log axes are fitted to each
   panel's data, so a 1 % change (lung fibroblast stiffness 321.7 →
   325.1) is drawn as a long arrow. Make each panel's x-range span at
   least one decade and y-range at least one decade, centred on the
   panel's data (geometric mean), so arrow length reflects relative
   change comparably across panels; and label each arrow end with its
   old/young stiffness ratio (2 decimals). Keep log axes.
3. **Cosmetics.** In `aging_vectors`, move the "2-D projection…" note
   so it does not overlap the x-axis label. In every `compare_summary`
   table, widen or wrap the `cell_type` column so names are not cut off
   ("hematopoietic precursor cell" is truncated).
4. Re-render only the affected figures (all `energy_transect_*`,
   `comparison/aging_vectors`, all `compare_summary`), update
