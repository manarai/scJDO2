# aging/A02 — Shared reference space and drift fits

## Summary
Completed A02 in `manus/aging-A02` using only the prescribed CPU workflow.
Young references and scArches-mapped old queries were fitted for lung and marrow,
along with standalone-old controls; all scVI fits used seed 0 and `max_epochs=400`.
The frozen-reference audit was exactly 0.0 for both tissues.
Three exact-score-matching energy-drift fits per tissue were completed and all
symmetry maxima were below the `1e-4` gate. Per-type basin fractions and all
required QC CSV summaries are committed; H5AD/model artifacts remain local.

1. `python -m pytest tests/test_compare_aging.py -q` — required pre-data test passed.

3. `python scripts/fit_tms_scvi.py --tissue marrow --seed 0` — final seed-0 CPU mapping.
4. `python scripts/fit_tms_drift.py --tissue lung --seed 0` — shared, standalone-young, standalone-old fits.
5. `python scripts/fit_tms_drift.py --tissue marrow --seed 0` — shared, standalone-young, standalone-old fits.
6. Read-back validation of all mapped/drift H5ADs and all six required QC CSVs.

## Deviations
- No frozen analysis parameter or hardware deviation occurred. Two implementation faults were found in discarded initial attempts: disabled scVI logging prevented validation-ELBO capture, and the first audit included decoder BatchNorm affine parameters that scArches intentionally keeps trainable. The implementation was corrected, all final maps were regenerated from seed 0, and the final audit covers exactly the frozen reference expression parameters specified by the task.
- The method specification's general CPU fallback says 200 epochs, but the A02 task's explicit Hardware rule supersedes it and required `max_epochs=400`; all final scVI fits used the 400 maximum with early stopping.

## Observations
- Frozen-reference maximum absolute parameter change was exactly 0.0 for both lung and marrow after query training.
- All six energy-drift fits had symmetry maxima between `8.87e-08` and `2.52e-07`.
- Lung shared-space holder fractions were high for both retained types, whereas marrow shared-space holder fractions varied substantially by annotated cell type.
- All scVI fits stopped before the 400-epoch cap; the marrow young reference ran longest at 364 epochs.

## Suggestions
- The next per-type comparison should explicitly apply the preregistered correction-artifact rule, because shared and standalone basin fractions differ for several type-age strata.
- Future interpretation should retain the A01 caveat about limited young-donor replication, especially marrow's two young donors.
