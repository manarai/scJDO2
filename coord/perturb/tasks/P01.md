# perturb/P01 — K562 data, control-only operator pilot, coverage and power

Runs in a **Manus cloud sandbox**: follow "Cloud sandbox runs" in
`coord/PROJECT.md`.

## Goal

Decide whether the pre-registered test P02 can run: enough strong
knockdowns, their target genes inside the operator's gene set **and**
carried by the fitted operator (role ≠ `unmeasured`), and a fit that fits
in a sandbox. **Do not compute any agreement between the operator and the
knockdown responses** (no correlations, captures or predictions of Δ from
M): P02 is the confirmatory test and must not be previewed.

## Data

Replogle et al. 2022, K562 essential-gene CRISPRi, raw single-cell counts:

* file `K562_essential_raw_singlecell_01.h5ad`, figshare file id 35773219,
  `https://ndownloader.figshare.com/files/35773219` (deposit
  `https://plus.figshare.com/articles/dataset/20029387`);
* expected 10,661,879,995 bytes, figshare md5
  `4f1122ce1c7f13299a68df6459a266d3`, required sha256
  `3e5a63a9e892b21029bb55fca4e12517a49aad7af6c14133ca63d12cf68c6cee`
  (verified by orient/S18 on 2026-10-22);
* `obs["gene"]` holds the target, `"non-targeting"` = controls; record the
  `obs` columns present and the gem-group distribution of controls.

Read it backed and in row chunks (it does not fit in RAM).

## Steps

1. **Environment.** venv, `pip install -e ".[dev]"`; run the required tests
   in `WORKSTREAM.md`. Record versions, CPU count, RAM, architecture.
2. **Download and verify** (sha256 must match; else stop).
3. **Expression.** Per cell: counts per 10k, `log1p` (call this L). Control
   gene set A = 2,000 highly variable genes of the controls
   (`scanpy.pp.highly_variable_genes`, flavor `seurat_v3` on raw counts of
   the controls, n_top_genes 2000).
4. **Pseudobulk responses** (all targets, chunked): Δ_j = mean L of cells
   with target j − mean L of all controls, over all genes.
5. **Qualifying knockdowns (fixed rule).** Target j qualifies if all hold:
   * ≥ 50 cells;
   * knockdown: mean CP10k of gene j in its cells ≤ 0.5 × control mean
     (gene j must be detected in controls: control mean CP10k ≥ 0.1);
   * response above noise: ‖Δ_j‖₂ over gene set A without j exceeds the
     95th percentile of 200 control-vs-control pseudo-responses (random
     n_j controls vs the remaining controls; `default_rng(0)`), computed
     for n = n_j rounded to the nearest of 50, 100, 200, 400, 800.
   Write `benchmarks/perturb/p01/targets.csv`: target, n_cells, control
   mean, knockdown fraction, ‖Δ‖ over A, noise q95, qualifies.
6. **Operator gene set B (fixed).** Qualifying targets ranked by ‖Δ‖
   (largest first), at most 500, then the HVGs of A in HVG rank order not
   already included, until |B| = 2,000. Write `gene_set_B.csv` (gene,
   source = target | hvg).
7. **Control operator, fit seed 0.** 2,000 control cells
   (`default_rng(0)`, uniform), raw counts on B. Mirror
   `scjdo2/routes/run.py` steps 1–3 with these changes: PCA (10 PCs) of L
   on B for these cells; direction = the snapshot score drift
   `scjdo2.energy_drift.EnergyDriftAdapter(dim=10)` with default config,
   `.fit(Z)`, `X_drift_v = .velocity(Z)`; `clock_calibrated = False`;
   `uns["scjdo2"]["meta"]["drift"] = {"method": "energy_score",
   "source": "snapshot"}`; J from the adapter's Jacobian. Then
   `fit_rate_and_gene_field` with the run.py defaults (`n_epochs_rate=150,
   k=30, cv_sample_cells=20, anchor_fit=True, n_anchors=300,
   anchor_top_k=10, anchor_max_live=200, seed=0`), `opspace.compute`, and
   `scjdo2.routes.dynamics.operator_tables(x, None, seed=0)`. Run it
   detached with a log. Save the fitted AnnData as
   `benchmarks/perturb/p01/control_fit_seed0.h5ad` (gitignored artifact;
   list it with sha256).
8. **Coverage.** A qualifying target j in B is **covered** if its role in
   `operator_tables(...)["roles"]` is not `unmeasured` in at least one
   archetype. Write `coverage.csv` (target, in_B, roles per archetype,
   covered). Report the number of archetypes, their member counts, and
   their `asym` values.
9. **Report** per PROTOCOL, with the gate table.

## Gate (feasibility, fixed)

* **F1** data: sha256 matches and `n_controls ≥ 2,000`.
* **F2** power: `n_covered ≥ 30` covered qualifying targets.
* **F3** cost: the seed-0 fit finished with peak RSS ≤ 16 GB; report its
  wall time and CPU hours (P02 needs three such fits).

F2 failing is a result (the test would be underpowered as designed):
report the counts and stop; do not change the rule, the gene-set size or
the cell number.

## Stop and ask

Checksum mismatch or download failure; `obs` has no target column with
`non-targeting` controls; any required test fails; a step would exceed
memory even when read backed; the fit crashes twice; any edit outside
`allowed_paths`.
