# reprog/C01 — Data inventory for the reprogramming route tests

Runs in a **Manus cloud sandbox**: follow "Cloud sandbox runs" in
`coord/PROJECT.md`. **No model fits** in this task.

## Goal

Build analysis-ready files for two lineage/time-course reprogramming
datasets and the counts C02 needs to write a pre-registration.

## Datasets

1. **CellTag MEF→iEP**, Biddy et al. 2018 (*Nature*), GEO GSE99915; the
   CellTag clone calls as published by the authors (GEO supplementary
   files or the Morris lab's published processed data).
2. **Schiebinger et al. 2019** (*Cell*), GEO GSE122662 (iPSC
   reprogramming time course; serum and 2i arms), with the authors' cell
   sets / annotations where published (e.g. the Waddington-OT data
   release).

Use only the authors' deposits; record every URL and the sha256 of every
downloaded file. **Do not call clones from raw reads.** If the published
clone calls cannot be found or cannot be matched to cell barcodes, stop
and ask.

## Steps

1. Environment as in PROJECT.md; `tests/test_routes.py`,
   `tests/test_smoke.py` pass.
2. Download; record URL, bytes, sha256.
3. Per dataset, write `benchmarks/reprog/c01/<name>.h5ad` (gitignored
   artifact): raw counts in `layers["counts"]`, `obs["day"]` (numeric),
   `obs["clone"]` (CellTag; string, NaN if none), the authors' state or
   cell-set annotation in `obs["state"]` (record its source; NaN if none),
   and for MEF→iEP the authors' reprogrammed / dead-end clone labels if
   published (`obs["clone_outcome"]`).
4. Inventory tables in `benchmarks/reprog/c01/`:
   * `cells_by_day_state.csv`;
   * `clones.csv` (MEF→iEP): clone, cells per day, days present,
     outcome label;
   * `clone_summary.json`: clones with cells on ≥ 2 days; clones with an
     outcome label; cells in them.
5. **Factor detectability** (`factors.csv`). For Hnf4a, Foxa1 (iEP) and
   Pou5f1, Sox2, Klf4, Myc (OKSM): is there a separate transgene feature
   in the deposited counts (e.g. a vector/cassette gene), or only the
   endogenous gene? Mean CP10k and fraction of cells detected per day.
   State only what the files show; do not infer transgene vs endogenous
   from expression levels.
6. Report per PROTOCOL.

## Gate (inventory, fixed)

* **I1** both datasets built with `day` for every cell and raw counts.
* **I2** MEF→iEP: ≥ 200 clones with cells on ≥ 2 days (needed for a
  held-out clone-fate test).

A failed gate is a result: report it; C02 adapts the design.

## Stop and ask

Clone calls unavailable or unmatched; the deposit has no raw counts;
annotations conflict with the paper; total download > 100 GB; any edit
outside `allowed_paths`.
