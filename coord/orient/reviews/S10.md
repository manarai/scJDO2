## Interpretation (Claude)
1. **Time-course OT flow J detects the fork almost perfectly on PCA** — with
   no labelling — the strongest result so far. But it **inverts on FA**: an
   embedding (representation) dependence that must be understood before any
   claim.
2. Labelling flow J is moderate; scVelo flow J and score J fail — consistent
   with S06/S11.
3. **Transition test design failed again (Claude's):** with LARRY-like
   growth, day 2 holds 1.5 % of cells, so equal-count pseudotime bins put
   the fork in bin 0–1. Fix: day-balanced binning (each day weighted
   equally; no cells removed).
4. **Guard works; Palantir default mode is unreliable on v3** — it moved
   every day-2 start to a late cell, and the guard refused all of them.
   Strict mode is the one to use.
5. **Diffusion is not recoverable here:** count noise in the embedding is
   larger than the biological spread over 48 h. A substantive negative
   result: score-J magnitudes cannot be calibrated this way.
6. Orientation `{lineage, pseudotime}` needs a v3 forward truth (the
   protected function raises for v3); OT null needs a time-course preset
   without a fork (the cycle has one time point).
