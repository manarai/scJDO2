# orient/S18d — Dose response along soft directions, depth-controlled

**Pre-registered** — every definition, group, threshold and statistic is
fixed here; report every number; change nothing after seeing results.
Runs in the **Manus cloud sandbox** as S18–S18c (reuse the environment and
the verified K562 and RPE1 files; git bundle back; never push; never the
user's Mac).

## Idea

Linear response: a weak push moves cells along the **soft** directions of
the landscape they start in. CRISPRi knockdown strength varies between
cells with the same guide, so the **weakly knocked-down** cells of a target
are its small-push regime. Prediction: their displacement from the controls
lies along score J's soft directions **computed from the control bulk** (no
information about where perturbed cells go) — for transcription-machinery
targets (programs that already fluctuate in controls), not for
mitochondria / translation targets (new stress programs). Sequencing depth
must not explain it.

## Data

RPE1 essential (primary; S18c's verified file) and K562 essential (report
only; S18's verified file). Controls = `"non-targeting"`.

## Fixed definitions

* **Two normalisations, both required:**
  * **N1:** S18's log-normalisation (median library size, `log1p`, 2 000
    control `seurat_v3` HVGs, control-only PCA-20), then the **depth axis
    projected out**: regress control PCA scores on `[1, log total counts,
    log genes detected]`; remove the fitted log-total-counts and
    log-genes-detected directions (orthonormalised) from every cell's PCA-20
    coordinates.
  * **N2:** analytic Pearson residuals (Lause et al. 2021; θ = 100, clipped
    at ±√n_controls) on the same 2 000 HVGs, control-only PCA-20.
* **Score J** per normalisation: `EnergyDriftAdapter`, S02 configuration,
  controls only. **Bulk operator** = mean `H` over **all** controls; **soft
  subspace** `S_J` = eigenvectors of `−H_bulk` with the 3 smallest positive
  eigenvalues (fewer than 3 positive → smallest |eigenvalue|).
  **Covariance subspace** `S_C` = top-3 eigenvectors of the control
  covariance. Save both (file + sha256) **before** reading any perturbed cell.
* **Groups:** S18c's T and M symbol rules, resolved against each screen's
  targets; analysed targets = significant (S18's energy-distance test, BH <
  0.01) with ≥ 150 cells. Record the lists.
* **Dose per cell:** knockdown = `1 − (target-gene counts / library size) /
  (control mean of the same)`; cells of a target split into tertiles by
  knockdown (ties by row order); **weak** = lowest tertile.
* **Weak displacement** `d_w` = centroid of the weak tertile − mean of all
  controls (PCA-20 of that normalisation). Targets whose target gene is not
  detected in ≥ 50 % of controls are excluded (dose undefined) — record.
* **Capture:** `‖P d_w‖² / ‖d_w‖²` for `S_J`, `S_C`, and 10 000
  covariance-matched random 3-dim subspaces (`default_rng(0)`).

## Gates (RPE1; each must hold in BOTH N1 and N2)

* **D1** median `S_J` capture of `d_w` over T targets > the 95th percentile
  of the random null.
* **D2** `S_J` capture > `S_C` capture over T targets: one-sided paired
  Wilcoxon p < 0.05.
* **D3** T > M in `S_J` capture: one-sided Mann–Whitney p < 0.05.
* If fewer than **10 T targets** qualify in RPE1, report underpowered.

Report only: K562 with the same pipeline; medium and strong tertiles; the
library size per group; |cos(`d_w`, depth axis)| per target (N1 before
projection).

## Amendment — Revision 1 (planner, 2026-10-22; fixed before any S18d result)

The executor proposed the following conventions before any S18d scientific fit, dose, capture or gate. The user explicitly approved all three and authorized this dated task amendment on 2026-10-22.

1. **D1 null:** Per screen/normalisation, draw `default_rng(0).standard_normal((10000,20,3))`, multiply by the symmetric square root of the all-control covariance, and apply reduced QR. Save/hash the bases before perturbed-cell access. The null is 10 000 **across-T median captures**, with one shared basis per draw; D1 compares the observed median with their 95th percentile.
2. **Tertiles:** Use `numpy.array_split` on ascending knockdown-sorted row indices, ties by original row order; extra cells go to earlier bins.
3. **Common cohort:** Use the accepted S18/S18c original log-normalized PCA-20 significance set (`BH < 0.01`, before depth projection), then filter for ≥ 150 cells and ≥ 50 % control target-gene detection. Keep the same cohort in N1 and N2.

The named exploratory implementation supplies the Pearson-residual convention and the report-only depth vector `B[1]/‖B[1]‖`; neither is changed. All remaining definitions, symbol rules, tests and gates are unchanged. Both normalisations' control-only score-J/covariance subspaces and random-null bases must be saved and hashed before reading any perturbed cell; T/M target lists and exclusions must be recorded before computing capture.
