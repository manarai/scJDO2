# orient/S01 — Synthetic multimodal trajectory generator

## Goal

One generator that produces, from a single known dynamical system, the
readouts every orientation source uses: lineage barcodes, metabolic
labelling (new/total counts with per-cell pulse), spliced/unspliced counts
(for the user's scVelo run), real sampling time (a time series), and counts
on which the user runs Palantir. It stores the exact truth needed to score
the orientation layer. **Build the generator and its validity tests only:**
do not run the orientation layer, scVelo or Palantir, and do not change any
protected path.

Every design choice below is fixed. If one cannot be implemented as
written, stop and ask.

## 1. Latent dynamics (hours; `d = 6`)

State `z = (z0, …, z5)`, simulated per cell as an SDE
`dz = F(z) dt + σ dW` (Euler–Maruyama, `dt = 0.1` h, `σ = 0.05`).

* `z1` — **progression**: `F1 = v1 (1 − z1 / z1_max)`, `v1 = 0.04` h⁻¹,
  `z1_max = 3`.
* `z0` — **pitchfork** gated by progression:
  `F0 = κ (μ z0 − z0³)`, `μ = z1 − z1_crit`, `κ = 0.5` h⁻¹, `z1_crit = 1.0`.
  Before `z1_crit` the progenitor sits at `z0 ≈ 0`; after it, cells commit
  to `z0 → ±√μ` (two fates).
* `(z2, z3)` — **cycling progenitor pool** (rotation):
  `F23 = g(z1) [ λ (ρ0² − r²) (z2, z3) + ω (−z3, z2) ] − (1 − g(z1)) c_exit (z2, z3)`,
  `r² = z2² + z3²`, `ρ0 = 1`, `λ = 0.1`, `ω = 2π / 20` h⁻¹ (20-h cycle),
  `c_exit = 0.2` h⁻¹, `g(z1) = 1 / (1 + exp((z1 − z1_crit) / 0.1))`
  (cells cycle before commitment and leave the cycle after it).
* `z4, z5` — **stable**: `F = −c z`, `c = 0.2` h⁻¹.

Initial founders: `z1 ~ N(0, 0.1)`, `z0 ~ N(0, 0.05)`, phase on the cycle
uniform with `r ~ N(1, 0.05)`, `z4, z5 ~ N(0, 0.3)`.

**Truth per cell**: `z_true`, `v_state = F(z)` at collection, the analytic
Jacobian `∂F/∂z` and its antisymmetric part `omega_state`, fate label
(`sign(z0)` if `z1 > z1_crit + 0.2`, else `"progenitor"`), true time.

## 2. Lineage and real time

* `N_founders = 300` founders at `t = 0`, each with a barcode (clone id);
  an override argument (`n_founders`) allows larger datasets.
* Division: each cell divides with rate `log 2 / 16` h⁻¹ (doubling time
  16 h; exponential waiting times); daughters copy the mother's full state
  (`z`, all RNA pools) and then evolve independently.
* **Sampling days** (real time): collect at `t = 24, 48, 72, 96` h. At each
  day, sample a fixed fraction `f_sample = 0.20` of the living cells
  (destructive: sampled cells are removed). In expectation this collects
  ≈ 170 / 380 / 870 / 1 970 cells on days 1–4 (≈ 3 400 in total) and
  ≈ 11 cells per clone. `f_sample` is fixed; nothing is adjusted to
  hit a cell count.
* Barcode detection: each collected cell's barcode is detected with
  probability `p_barcode = 0.6` (knob); undetected → no clone label.
* Store `obs["day"]` (1–4), `obs["time_hours"]` (collection time),
  `obs["clone"]` (string or missing) and `obsm["clone_matrix"]` (sparse,
  cells × clones, LARRY style), `obs["clone_true"]` (always present).

## 3. Genes and kinetics

* `G = 800` genes. Transcription rate `α_g(z) = exp(W_g · z + b_g)`
  molecules h⁻¹; `W` sparse — each gene loads on 1–3 latent dimensions
  chosen at random, weights `N(0, 1)`; `b_g ~ N(log 2, 0.7)`.
* Per-gene splicing `β_g ~ LogNormal(log 3, 0.5)` h⁻¹ and degradation
  `γ_g ~ LogNormal(log 0.2, 0.6)` h⁻¹ (median half-life ≈ 3.5 h).
* Integrate `du/dt = α(z(t)) − β u`, `ds/dt = β u − γ s` along each cell's
  own history (same `dt`), from founders initialised at steady state for
  their initial `z`. Daughters inherit pools.
* Truth: `layers["u_true"]`, `layers["s_true"]` (pre-noise) and the exact
  expression velocity `layers["ds_dt_true"] = β u − γ s` at collection.

## 4. Counts and labelling

* Per-cell capture `s_c ~ LogNormal(log 0.1, 0.3)`. Observed
  `layers["unspliced"] ~ Poisson(s_c · η_u · u)`, `η_u = 0.3`;
  `layers["spliced"] ~ Poisson(s_c · s)`. `X` = spliced.
* **Labelling**: each cell has a pulse duration `t_p` (h) before
  collection; default all cells `t_p = 2` (knob: a list, e.g. `[1, 2, 4]`
  assigned by collection batch). Track a parallel *new* pool that starts at
  0 at `t_collect − t_p`: `du_new/dt = α − β u_new`,
  `ds_new/dt = β u_new − γ s_new`. Observed new = `Binomial(new_obs, ε)`
  with labelling efficiency `ε = 0.9` (knob), where `new_obs` is drawn as
  part of the total counts (draw total first, then split new vs old with
  the true new fraction). Store `layers["new"]`, `layers["total"]`
  (= spliced + unspliced observed), `obs["pulse_hours"]`. These must be
  the inputs `scjdo2.labelled_rates.LabelledRateModel.fit(counts_new,
  counts_total, z, t_c)` takes.

## 5. Preprocessing and truth in the embedding

`scjdo2/data/synthetic_multimodal.py` provides
`embed_linear(adata, method="pca"|"fa", n_comp=20)` that normalises total
counts (target = median library size), takes `log1p`, fits PCA or factor
analysis on **spliced**, and stores `obsm["X_pca"]` / `obsm["X_fa"]` and
the loadings, mean and normalisation factors in `uns`. It also provides
`true_velocity_in_embedding(adata, method)`: the exact expression velocity
`ds_dt_true` mapped into the embedding by the chain rule through the
normalisation and `log1p`, then the linear map (FA: the posterior-mean map
`Wᵀ(WWᵀ + Ψ)⁻¹`, not the pseudoinverse). Store it as
`obsm["velocity_true_pca"]` / `obsm["velocity_true_fa"]`.

## 6. Presets (each a function argument set, all seeded)

* `"default"` — as above.
* `"stress"` — `p_barcode = 0.3`, `ε = 0.6`, `t_p ∈ {1, 2, 4}` by day, and
  20 % of genes with **assumption-breaking kinetics**: `β_g` doubles
  half-way through the simulation for those genes (record which).
* `"batch"` — `"default"` plus a per-day multiplicative gene effect
  `LogNormal(0, 0.3)` on capture (record the factors).
* `"stationary_cycle"` — no progression (`v1 = 0`, `z1` fixed at 0): a
  steady cycling pool for the rotation and stationarity flags; one
  sampling day; lineage optional.

## 7. Outputs

* `scjdo2/data/synthetic_multimodal.py` — `make_multimodal(preset, seed,
  **overrides) -> AnnData`, `embed_linear`, `true_velocity_in_embedding`.
* `scripts/make_synthetic_multimodal.py --preset <name> --seed <s>` →
  `benchmarks/synthetic_multimodal/data/<preset>_s<seed>.h5ad`
  (gitignored) for presets × seeds {0, 1, 2}.
* `benchmarks/synthetic_multimodal/MANIFEST.csv` (committed): preset,
  seed, path, sha256, n_cells, n_clones_detected, f_sample, knob values.
* `docs/SYNTHETIC_MULTIMODAL.md`: what each key holds, which keys the user
  points scVelo (`spliced`, `unspliced`) and Palantir (the PCA/FA
  embedding, `uns["suggested_start_cell"]`: the earliest-day cell nearest
  `z1 = 0`) at, and which keys are truth (never inputs).

## 8. Validity tests (`tests/test_synthetic_multimodal.py`; all must pass)

1. Determinism: same preset + seed → identical arrays.
2. Kinetics: with noise off (`σ = 0`, no Poisson), `ds_dt_true` equals the
   finite difference of `s_true` along a cell's history (relative error
   ≤ 1e-3). **Velocity signal** (amended in review, Revision 1): on
   `u_true`, `s_true` of the default preset, the spliced lag
   `|γ s − β u| / (β u) > 0.2` holds in ≥ 10 % of cells for ≥ 25 % of genes
   (≥ 200 genes — what scVelo needs). Report the lag fraction per day.
   (The earlier check on unspliced, `|u − α/β| / (α/β)`, tested the wrong
   pool: splicing is fast, so `u` tracks transcription almost instantly.)
3. Truth mapping: with noise off, `true_velocity_in_embedding` agrees with
   the finite difference of the embedded expression over one `dt`
   (median cosine ≥ 0.99), for PCA and FA.
4. Lineage: every detected clone label maps to one founder; with the
   default preset ≥ 50 % of detected clones span ≥ 2 days; the detected
   fraction is `p_barcode ± 0.03`.
5. Labelling: with noise off, the new fraction per gene matches its
   analytic expectation from the simulated pools (relative error ≤ 1e-3);
   `LabelledRateModel.fit` runs on the default preset (a few epochs) and
   returns finite γ.
6. Time and dynamics: day labels match collection times; the fraction of
   committed cells increases with day; in `"stationary_cycle"` the
   rotation truth `omega_state` is non-zero and equals `ω` in the (z2, z3)
   block for cells with `g ≈ 1`.
7. Sizes: default **total collected** cells across the four days ≈ 3 400 (within ± 15 %, i.e. 2 900–3 900), 800 genes, all layers present; `n_founders` override scales it.
