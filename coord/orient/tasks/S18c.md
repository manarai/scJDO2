# orient/S18c — Soft valleys, pre-registered, independent screen

**Pre-registration.** Everything below — data, gene groups, valley
definition, statistics, thresholds — is fixed before any RPE1 perturbed cell
is examined. The K562 observation that motivated it is exploratory; this
task is the confirmation. Do not change any definition after seeing RPE1
results; report every number.

Runs **in the Manus cloud sandbox** as S18 / S18b (fresh or existing venv,
git bundle back, never push, never the user's Mac).

## Fixed definitions

* **Embedding:** S18's recipe on each screen's **controls only** (median
  library normalisation, `log1p`, 2 000 `seurat_v3` HVGs on control counts,
  PCA-20 fitted on controls; project all cells).
* **Score J:** `EnergyDriftAdapter`, S02 configuration, controls only;
  per-control-cell `H` (Jacobian of the score).
* **Targets analysed:** ≥ 100 cells and significant by S18's energy-distance
  test (200 permutations, BH < 0.01); **strong** = top 20 % of significant
  targets by energy distance.
* **Gene groups (by symbol, resolved against the screen's targets before
  analysis; record the lists):**
  * **T, transcription machinery:** `MED*`, `TAF*`, `GTF2*`, `POLR2*`,
    `INTS*`, `SUPT4H1`, `SUPT5H`, `SUPT6H`, `SUPT16H`, `PAF1`, `CTR9`,
    `LEO1`, `CDC73`, `RTF1`.
  * **M, mitochondria / translation:** `MRPL*`, `MRPS*`, `TIMM*`, `TOMM*`,
    `PHB`, `PHB2`, `HSPA9`, `EIF2S1`, `EIF2S2`, `EIF2S3`, `EIF2B*`, `EIF3*`,
    aminoacyl-tRNA synthetases (`*ARS`, `*ARS2`), `GSPT1`, `HBS1L`.
  * If fewer than **8 strong T targets** exist in RPE1, report underpowered
    and stop the confirmation (still report everything).

## Step 1 — soft valleys from controls only (before touching perturbed cells)

1. Control mean μ; **edge cells** = controls in the outer 20 % by
   Mahalanobis distance (control covariance).
2. For each edge cell: local operator = mean `H` over its 200 nearest
   controls; `u` = eigenvector of `−H` with the smallest positive eigenvalue
   (none positive → smallest |eigenvalue|), signed outward
   (`u · (z − μ) > 0`); softness `s` = that eigenvalue.
3. **Valley directions:** k-means (K = 5, `random_state=0`) on the unit
   vectors `u` of the 25 % softest edge cells; centroids normalised →
   `v_1 … v_5`. **Save them (file + sha256) before Step 2.**
4. **Covariance baseline directions:** top-5 eigenvectors of the control
   covariance, `e_1 … e_5`.

## Step 2 — alignment of knockdown shifts

For each strong target: `d` = centroid − mean of **all** controls (unit
vector). **Valley alignment** `A_J = max_k |cos(d, v_k)|`; covariance
alignment `A_C = max_k |cos(d, e_k)|`. **Null:** 10 000 random directions
drawn from N(0, Σ_controls) (covariance-matched), `default_rng(0)`, giving
the null distribution of `A_J`.

## Gates (fixed now; RPE1, PCA-20)

* **C1** median `A_J` over strong **T** targets > the 95th percentile of the
  covariance-matched null.
* **C2** `A_J`(T) > `A_J`(M): one-sided Mann–Whitney p < 0.05.
* **C3** `A_J`(T) > `A_C`(T): one-sided paired Wilcoxon p < 0.05.

All three must pass to call the K562 observation **confirmed**. Report only:
K562 with the same pipeline; PCA-15 / 30; K = 3 / 8; all targets (not only
strong); per-target tables.

## Amendment — Revision 1 (planner, 2026-10-22; fixed before any RPE1 result)

Cutoff and tie convention, as proposed by the executor before analysis:
edge cells = the `ceil(0.20 × n_controls)` controls with the largest
Mahalanobis distance; soft edge cells = the `ceil(0.25 × n_edge)` edge cells
with the smallest softness `s`; strong targets = the
`ceil(0.20 × n_significant)` significant targets with the largest energy
distance. Numerical ties are broken by original control-row order (cells)
or lexicographic target symbol (targets). All other definitions, library
defaults (incl. `KMeans(random_state=0)`) and gates are unchanged.
