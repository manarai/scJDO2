# orient/S08 — Real-data reference statistics

## Goal

Measure, on real datasets, the statistics that decide whether the
synthetic generator is realistic for each readout (counts, splicing,
labelling, lineage, time course, embedding structure), and measure the
**same statistics with the same code** on the v2 synthetic data. This
task only measures: it does not change the generator (that is S09, built
from these numbers) and runs no orientation method.

## Common preprocessing (identical for real and synthetic)

For each dataset: genes with ≥ 10 counts in total kept; **gene set for
per-gene statistics** = the 800 genes with highest mean count among those
(synthetic: its 800 genes); cell clusters for within-cluster statistics =
Leiden (resolution 1.0, seed 0) on PCA (30 comps; 20 for synthetic) of
log1p library-normalised counts (target = median library size), 800 HVGs
(scanpy `seurat_v3` on counts). Synthetic: `v2_default`, `v2_stress`,
`v2_batch` seeds 0–2 and v1 `default` seeds 0–2 (reference), using `X`
(= spliced) as the count matrix and their layers as below.

## Statistics (`scripts/s08_reference_stats.py`; one function per statistic, same code for all datasets)

**C — counts** (all raw-count datasets and synthetic; matrix = spliced
where present, else `X`; `scnt_hema` = `total`):
* C1 library size per cell: median, IQR, sd of log10.
* C2 genes detected per cell / genes kept.
* C3 per-gene log10 mean (gene set): quantiles 5, 25, 50, 75, 95.
* C4 overdispersion: per gene and cluster (clusters ≥ 50 cells), on
  library-normalised counts, method-of-moments `φ = (var − mean)/mean²`
  (genes with mean ≥ 0.1 in that cluster); median over clusters per gene;
  quantiles of `φ` over genes.
* C5 excess zeros: per gene, observed zero fraction minus the
  NB-expected one at that gene's mean and `φ`; quantiles.
* C6 |Pearson r| among the top 200 HVGs (log-normalised): quantiles.
* C7 PCA of log-normalised 800 HVGs: variance ratio of PCs 1–20,
  participation ratio `(Σλ)²/Σλ²` of the 50-PC spectrum.

**S — splicing** (`pancreas`, `dentate`, `setty`, `scnt_hema`, synthetic):
* S1 unspliced share of counts `Σu / Σ(u+s)`.
* S2 per gene `Σu/Σs` (gene set): quantiles.
* S3 phase-portrait shape, per gene on kNN-30 moments (scVelo
  `pp.moments` on the PCA above): steady-state line `u = γ' s` by the
  5 % extreme-quantile fit; fraction of cells above (`f_up`) and below
  (`f_down`) the line by > 10 % of `u`; classify each gene as `cycle`
  (both ≥ 0.1), `induction` (only `f_up` ≥ 0.1), `repression` (only
  `f_down` ≥ 0.1) or `steady` (neither). Report the class shares.
* S4 scVelo dynamical (S03 settings: `filter_genes(min_shared_counts=20)`,
  normalise, `scanpy.pp.log1p`, neighbours on PCA, moments,
  `recover_dynamics`): fraction of genes recovered, `fit_likelihood`
  quantiles, fraction with `fit_likelihood ≥ 0.3`.

**L — labelling** (`scnt_hema` per labelling time; `scnt_neuron` ratios
only; synthetic):
* L1 per-gene new/total (`Σnew/Σtotal`, gene set) by labelling time:
  quantiles; overall new/total.
* L2 half-lives: `LabelledRateModel` fitted as in S02 (`z` = the PCA
  above, `t_c` = labelling hours) on `scnt_hema` and synthetic; quantiles
  of `log(2)/γ` in hours. Also the half-life columns stored by dynamo in
  `~/Documents/scJDO2/benchmarks/data/dynamo_hematopoiesis/data/hematopoiesis.h5ad`
  `var` (read only), for comparison.
* L3 zero fraction of `new` per gene vs log mean `new`: binned medians.

**G — lineage and time** (`larry`; synthetic):
* G1 fraction of cells with a barcode; cells per time point.
* G2 detected clone size: quantiles; fraction of clones of size 1.
* G3 fraction of clones (and of barcoded cells) seen on ≥ 2 time points;
  per pair of time points.
* G4 for clones on ≥ 2 time points: distribution of min(cells on earliest,
  cells on latest time point) — the §17 rule's input.
* G5 fate composition by time point (LARRY annotation: undifferentiated vs
  each fate; synthetic: `fate_true` progenitor vs committed, scoring only).

**T — trajectory structure** (all datasets): T1 participation ratio (C7);
T2 Palantir on PCA (S03 settings) from the cell with the lowest
`palantir_pseudotime` (`setty`) or, elsewhere, the earliest-time cell
nearest the centroid of the earliest time point (`larry`, synthetic): number
of terminal states found, and the entropy of the fate probabilities
(median) — report only. **Amended in review (Revision 1):** `dentate` —
`obs["age(days)"]` is the animals' sampling age, a measured readout: use
the earliest age as its time point. `pancreas` has no time field: T2 is
**not applicable** there (record it, do not substitute an annotation).

## Comparison (`scripts/s08_compare.py`)

For each statistic: distance between two datasets = KS statistic for
distributions, `|log(a/b)|` for scalars, total-variation distance for
class shares. Also report, for every scalar and every distribution's
median, whether the synthetic value lies **within the range of the real
values** (min–max over real datasets; amended in review — where real
datasets differ by technology the spread-based tolerance alone is very
permissive). **Real spread** = largest distance between two real datasets
that have that statistic (if only one real dataset has it, the fixed
tolerance applies: KS 0.2, `|log ratio|` `log 1.25`, TV 0.15). A synthetic
dataset **matches** a statistic if its distance to every real dataset is
≤ max(real spread, fixed tolerance). Report a matrix: synthetic dataset ×
statistic → distance, nearest real dataset, match yes/no.

## Outputs

`benchmarks/real_reference/{stats.csv (dataset × statistic × value),
distributions/ (per-statistic quantile tables), compare.csv,
RESULT_S08.md}` (what ran, the match matrix, no interpretation); figures
under `benchmarks/figures/real_reference/` (one panel per statistic, real
datasets vs synthetic presets).

## Gates

None on the synthetic data (this task measures). Required: every statistic
computed for every dataset that has the readout; real-data integrity
checks pass; the same function computes each statistic for real and
synthetic data (assert in code).

## Run procedure

One dataset × statistic group per command, detached, timed, with a
checkpoint; check back between units (Manus's 2-h wait limit). LARRY is
large (130 887 cells): compute G-statistics on all cells; C/T statistics
on a fixed random subsample of 20 000 cells (`default_rng(0)`), stated in
the result. A unit over 60 min: stop, record, rerun once alone; if again,
stop and ask.
