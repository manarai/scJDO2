# orient/S11 — Flow J on real data: do independent sources agree?

## Goal

Without synthetic truth, test whether the **flow operator** `J_flow`
(Jacobian of a drift fitted to a measured velocity) is reproducible on real
data: build it from **independent velocity sources on the same cells** and
measure their agreement against a permutation null; compare with
**dynamo's** vector-field Jacobian (the established method); compute the
score operator `J` on the same embedding and the per-cell **score-vs-flow
agreement**. Report what each dataset shows; no generator, no orientation
layer. S09 stays paused until this task is done.

## Velocity sources

**scnt_hema** (three independent):
1. `labelling` — `LabelledRateModel` on raw `new`, `total`, `z = X_pca30`,
   `t_c = obs["time"]`; `v_g = α̂ − γ·total` with `α̂ = γ·new/(1−e^{−γ t})`
   (S02's formula, import `scripts/orient_end_to_end.py`'s helpers); chain
   rule into `X_pca30`.
2. `scvelo` — S03's settings on raw `spliced` / `unspliced` with
   neighbours on `X_pca30`; gene velocity mapped by the same chain rule
   (scVelo's `velocity` layer on its genes; genes not in the PCA set: 0).
   **Non-finite values (amended in review, Revision 3)** — as scVelo itself
   does for its own projections: use a gene's velocity only if
   `var["velocity_genes"]` is True **and** the gene is finite in every cell;
   every other gene contributes 0. If a cell still has a non-finite mapped
   velocity, drop that cell from the scVelo source only. Report the number
   of genes used / zeroed and cells dropped. Apply the same rule to
   `dynamo_gene` (genes non-finite in any cell → 0).
3. `dynamo_gene` — dynamo's gene-level `layers["velocity_alpha_minus_gamma_s"]`
   from the processed file, mapped by the same chain rule (read only; this
   is dynamo's labelling-based velocity, not ours).

**larry** (two independent):
1. `ot` — entropic OT between consecutive time points on the subsample
   (moscot if it installs, else POT `ot.sinkhorn`, ε = 0.05 × median squared
   distance; balanced only — the growth-weighted unbalanced sensitivity is
   **omitted** (amended in review, Revision 2: LARRY has no measured growth
   rates, so its marginals and `reg_m` would be arbitrary; it moves to S10,
   where the generator's growth is known); record which library), barycentric velocity / 48 h for day-2 and day-4 cells.
2. `lineage` — for every barcoded day-2 / day-4 cell whose clone has cells
   on the next time point: (mean position of the clone's next-time-point
   cells − the cell's position) / 48 h, computed on **all** cells projected
   into the PCA, then restricted to the subsample.

## Operators (per dataset, per source)

* `J_flow` = `MeasuredDrift(30, seed=0)` fitted on the cells that have the
  velocity; Jacobian by autodiff at every cell. Also with seeds 1, 2
  (estimator variability).
* `J_local` = the local ridge regression (`scjdo2.orient.base.local_jacobian`,
  k = 30) of the same velocity (estimator sensitivity).
* **dynamo baseline:** dynamo's SparseVFC vector field fitted to the same
  velocity in `X_pca30` and its analytic Jacobian (dynamo's `vf.SparseVFC`
  / `vf.jacobian` API; record version). For `scnt_hema` also dynamo's
  stored `VecFld_pca` Jacobian in its own PCA — report-only, invariants only
  (different basis). dynamo currently fails to import in `.venv`
  (statsmodels): use a separate `.venv-dynamo` for dynamo steps only; if it
  cannot run, stop and ask.
* `J_score` = `EnergyDriftAdapter` (S02 config) on `X_pca30`.

## Comparisons (`scripts/s11_compare.py`)

For every pair of sources (and estimator pairs, seeds), per cell where both
are defined:
* velocity agreement: cosine;
* operator agreement: relative Frobenius distance
  `‖J_a − J_b‖ / ½(‖J_a‖ + ‖J_b‖)`; Spearman over cells of the leading
  real eigenvalue `λ₁`; |cos| of the leading eigenvectors;
* **null:** 5 permutations of each source's velocity vectors across cells
  (`default_rng(s)`), refit, same agreement numbers → null distribution.
* score vs flow: per cell |cos| between the leading eigenvectors of `J_score`
  and `J_flow` and the Spearman of `λ₁`; by cell type.
* per cell type (annotation): median `λ₁` of each operator; fraction of
  cells with `λ₁ > 0`.

## Criteria (fixed now)

For each dataset and each pair of **independent** sources
(`scnt_hema`: labelling–scvelo, labelling–dynamo_gene, scvelo–dynamo_gene;
`larry`: ot–lineage), with the `MeasuredDrift` estimator, seed 0:

* **Reproducible:** the operator agreement (Spearman of `λ₁` and median
  |cos| of leading eigenvectors) exceeds the largest of its 5 null values.
* **Estimator-robust:** for the same source, `MeasuredDrift` vs `J_local`
  and vs dynamo's SparseVFC agree above their nulls likewise.

Every number is reported; a pair failing a criterion is a result. Nothing
here is tuned.
