# orient/S06 — The S02–S04 pipeline on the v2 generator

## Goal

Rerun the whole orientation evaluation on the **v2** datasets (S05), which
are fair to every readout: fit the energy drift and labelling velocity
(as S02), run scVelo and Palantir (as S03, with realistic start cells as
S04 intended), score every source combination for both outputs with the
reliability check (§15) on and off, and check whether the operator `J`
reads forks and basins where the truth has them. This supersedes S04.

**Never use truth as an input** (S02 rule and key list, plus the v2 truth
keys `var["gene_kind"]`, `theta`, `delta`, `fate_sign`, `nb_theta`).
Truth is read only for scoring, after every `orient` call. Day-1 start
cells are chosen from `obs["day"]` only.

## Inputs (read, never modified)

v2 datasets from `benchmarks/synthetic_multimodal/MANIFEST_v2.csv`
(sha256 check): `v2_default`, `v2_stress`, `v2_batch` × seeds 0–2;
`v2_stationary_cycle` × seeds 0–2 (flags only). Record the versions of
python, numpy, scikit-learn, torch, scvelo, palantir, scanpy (FA depends on
the scikit-learn version — review S05).

## Step 1 — Fitted units (`scripts/s06_fit_units.py`)

Exactly S02's step 1–2 (`scripts/orient_end_to_end.py`: `fit_unit` /
`labelled_velocity` / `chain_rule_count_velocity`; **import, do not
edit**), on PCA and FA, writing to
`benchmarks/synthetic_multimodal/data/s06/<preset>_s<seed>_<method>.h5ad`:
energy drift (same `EnergyDriftConfig`), `uns["scjdo2"]["J"]`,
`obsm["X_drift_v"]`, `obs["energy"]`; `LabelledRateModel` fit; raw and
smoothed labelled velocity. Symmetry max ≤ 1e-4, else stop.

## Step 2 — scVelo and Palantir (`scripts/s06_user_runs.py`)

* **scVelo:** exactly S03's settings (import the scVelo part of
  `scripts/run_scvelo_palantir_s03.py`; do not edit it); dynamical primary,
  stochastic optional as in S03.
* **Palantir:** S03's settings, with `early_cell` = each of 5 day-1 cells
  `np.random.default_rng(1000 + seed).choice(day1_names, 5, replace=False)`,
  in two modes:
  * `default` — Palantir's own behaviour (`use_early_cell_as_start=False`):
    it replaces the given cell by the nearest diffusion-map boundary cell
    (found in review; this is why S04's roots gave identical pseudotimes);
  * `strict` — `use_early_cell_as_start=True` (sensitivity).
  * **negative control** (amended before start): additionally 5 **day-4**
    cells `np.random.default_rng(2000 + seed).choice(day4_names, 5,
    replace=False)`, in both modes. A reversed start must not pass
    silently.
  For every run store `obs["palantir_pseudotime"]` and set
  `uns["palantir_start_cell"]` to **the cell Palantir actually started
  from** (the argmin of its pseudotime); record the given cell, the actual
  start, whether they differ, and the actual start's day.
* Files under `benchmarks/synthetic_multimodal/data/s06_user/`, holding only
  the added keys (as S03); manifest with sha256.

## Step 3 — New developmental truth (generator, truth only)

With sparse lineage sampling most true clones are seen on one day, so the
S03 chord truth exists for few cells. Add to
`scjdo2/data/synthetic_multimodal.py` (new function; protected functions
untouched):

`forward_developmental_truth(adata, method, horizon_hours=24.0, n_paths=8,
seed=0)`: for each cell, from its `z_true`, `u_true`, `s_true`, simulate
`n_paths` latent paths for `horizon_hours` with the generator's own SDE
(`_state_drift`, same σ, dt; divisions ignored — daughters copy state) and
integrate its RNA pools along each path with the preset's own `α`
(`_v2_alpha` for v2) and `_rna_step` (β regime as at collection); map the
cell's current and mean future **expected** counts (`capture_factor ×
batch effect × s`, no noise) through the stored embedding (normalise to
the stored target, `log1p`, `(x − mean) @ linear_map`) and return
`future − current` (n, d). Seeded and deterministic. Store as
`obsm["dev_truth_forward_<method>"]` in the scoring copy only.

Test (`tests/test_synthetic_multimodal.py`; **amended in review,
Revision 1** — the per-cell chord comparison was a weak reference under
sparse sampling, see `reviews/S06.md`): on v1 `default` seed 0 and
`v2_default` seed 0, with the expected embedded positions `z_exp` (as the
chord truth) and the forward truth `fw`:

* **population check (gate):** for each consecutive day pair d → d+1,
  cosine between the mean of `fw` over day-d cells and
  `mean(z_exp[day d+1]) − mean(z_exp[day d])` ≥ 0.95;
* **per-cell check on v1 only (gate):** median cosine between `fw` and the
  chord truth over cells of clones with ≥ 3 cells on both their earliest
  and latest day ≥ 0.85;
* report (no gate): the per-cell chord comparison for both datasets, all
  cells and by minimum clone cells at both ends (1, 2, 3, 5).

If a gate fails, stop and ask — do not change the definition.

## Step 4 — Scoring (`scripts/s06_score.py`)

Import S03's helpers from `scripts/orient_end_to_end_s03.py` (do not edit).
Per dataset × embedding (PCA primary, FA) × Palantir run, raw labelling
primary (smoothed as sensitivity):

1. **Combinations:** flow `{labelling}`, `{velocity}`, `{labelling,
   velocity}`; dev `{lineage}`, `{pseudotime}`, `{lineage, pseudotime}`;
   all four. Each with the reliability check **on** (default) and **off**
   (`reliability_min={}`); additionally once with
   `reliability_min={"velocity": 0.6, "pseudotime": 0.0}` to read the
   lineage–pseudotime agreement.
2. **Truths:** flow → `true_velocity_in_embedding(a, method, at="expected")`;
   dev → **forward truth** (primary) and chord truth (where defined, report).
3. **Scores** as S03 (sign agreement, oriented fraction, moving axes
   `|cos| ≥ 0.2`, by day; coverage added and agreement on cells each
   source decides; ranking check; `flow_vs_dev` by day; independence; J
   hash), plus per run `orient_meta["reliability"]` (status, agreement,
   n_pairs) and the actual-start-cell diagnostics.
4. **J basin/fork check** (PCA and FA, per dataset; no orientation input):
   per cell `lead = max eigenvalue of J` (J is symmetric). Truth classes
   from `z_true` (scoring only), with `μ = z1 − 1.0`:
   * `saddle`: `μ ≥ 0.1` and `|z0| < 0.3·√μ`;
   * `committed`: `μ ≥ 0.3` and `| |z0| − √μ | < 0.3·√μ`;
   * `progenitor`: `z1 < 0.8`.
   Report per class: n, median `lead`, fraction `lead > 0`; **AUC** of
   `lead` separating `saddle` (positive) from `committed`; and at saddle
   cells the |cosine| between J's top eigenvector and the fate axis
   (day-4 centroid of `fate_true == "positive"` minus `"negative"` cells in
   the embedding, normalised).
5. Flags on `v2_stationary_cycle` and per preset (as S02).
6. **Negative control:** for every day-4-root run, call
   `orient(..., ["pseudotime"])` and record whether the §16 real-time guard
   refuses it (ValueError) or accepts it, with `Spearman(pseudotime, day)`,
   the actual start's day, and — if accepted — its agreement with the
   forward truth. Also record the guard's Spearman for every day-1 run.

`benchmarks/synthetic_multimodal/s06/{results.csv,summary.csv,by_day.csv,
palantir_runs.csv,j_check.csv,RESULT_S06.md}` (what ran, gates verbatim,
tables, pass/fail, no interpretation); figures under
`benchmarks/figures/orient/s06/` (agreement per combination × preset, check
on vs off; pseudotime by Palantir mode; J `lead` by truth class).

## Gates (fixed now; `v2_default`, PCA, raw labelling, seeds 0–2; Palantir `default` mode, all 5 roots)

* **Flow**
  * `{labelling}` agreement ≥ 0.85, oriented fraction ≥ 0.3.
  * With the check on, `{labelling, velocity}` agreement ≥ `{labelling}`
    agreement − 0.03, and oriented fraction ≥ `{labelling}`'s.
* **Developmental** (forward truth)
  * `{lineage}` agreement ≥ 0.90 (its oriented fraction is report only).
  * `{pseudotime}` agreement: median over the 15 runs ≥ 0.85, minimum ≥ 0.80.
  * `{lineage, pseudotime}` oriented fraction ≥ 0.80.
* **Independence** exact and **J unchanged** in every call.
* **Flags:** `v2_stationary_cycle` `non_equilibrium` on ≥ 0.8 of cells with
  an identified flag (all seeds).
* **J check:** AUC (saddle vs committed) ≥ 0.75 on every seed.
* **Negative control:** every day-4-root run is either refused by the §16
  guard or, if accepted, its actual start cell is on day 1 or 2 (Palantir
  snapped it back); no accepted run has pseudotime agreement with the
  forward truth < 0.5. No day-1-root `default`-mode run is refused.

Everything else (`{velocity}` alone, ranking checks, `stress`, `batch`, FA,
smoothed labelling, `strict` Palantir mode, chord truth, by-day, moving
axes) is report only. A failed gate is a result — report it with
`status: done`; do not tune anything to pass.

## Run procedure

One dataset at a time per step, each timed (`/usr/bin/time -l`); a step
for one dataset over 60 min: stop it, record timing and environment, rerun
it once alone; if it again exceeds, stop and ask. Other jobs may share the
machine; do not stop them.

## Stop and ask

An input checksum fails; a symmetry check exceeds 1e-4; scVelo or Palantir
cannot run with these settings or change cell order / `X_pca`; the forward
truth test fails; anything would need a truth key as an input, a refit
outside this task, an edit to S02/S03 scripts or a protected path; compute
over budget.
