# orient/S04 — Realistic Palantir roots; flow with the reliability check

## Goal

Two things, both on the S03 data:

**B. Pseudotime without a truth-chosen root.** In S03, Palantir's start
cell `uns["suggested_start_cell"]` came from the truth (best case);
pseudotime then reached 0.913 against the developmental truth. Rerun
Palantir with start cells an analyst could pick without the truth — random
**day-1** cells (the earliest sampling day) — and score again.

**A. Flow with the reliability check.** `orient` now demotes velocity to a
cross-check when it agrees with labelling below 0.6 on (cell, axis) pairs
both sign (`docs/ORIENTATION_SPEC.md` §15, commit on the base branch).
Re-score the S03 flow combinations with it on, which is now the default.

**Never use truth as an input** (same rule and key list as S02/S03).
Palantir reads only `X_pca` and its start cell; the start cells are chosen
only from `obs["day"]` with the seeded generator below. Truth keys are used
only for scoring, after every `orient` call.

## Inputs (read, never modified)

* S01 datasets `default`, `stress`, `batch` × seeds 0–2 (sha256 against
  `MANIFEST.csv`).
* S02 units `benchmarks/synthetic_multimodal/data/s02/<preset>_s<seed>_<method>.h5ad`
  and S03 user files `benchmarks/synthetic_multimodal/data/user/<preset>_s<seed>_user.h5ad`
  (sha256 against S03's report manifest). **No refit of the energy drift,
  labelling or scVelo.**

## Step 1 — Palantir with five realistic roots (`scripts/run_palantir_roots_s04.py`)

For each of the 9 datasets: day-1 cells `D1 = obs_names[obs["day"] == 1]`;
`roots = np.random.default_rng(1000 + seed).choice(D1, 5, replace=False)`
(`seed` = dataset seed; the same draw for every preset with that seed is
fine — record the names). For each root, on a copy, run Palantir with
**exactly S03's settings** (diffusion maps on `X_pca`, 10 components,
multiscale space, `run_palantir`, `num_waypoints = 500`, `knn = 30`,
`seed = 0`), `early_cell = root`. Write
`benchmarks/synthetic_multimodal/data/user_s04/<preset>_s<seed>_root<r>.h5ad`
(r = 0–4) holding **only** `obs["palantir_pseudotime"]`,
`uns["palantir_start_cell"]` and the obs names; record a manifest (path,
sha256, root name, wall time, Palantir version).

## Step 2 — Scoring (`scripts/orient_s04.py`)

Import S03's helpers from `scripts/orient_end_to_end_s03.py` (`load_joined`,
`chord_truth`, `expected_flow_truth`, `truth_masks`, `score_group`,
`source_addition`, `call_orient`, …); **do not edit that script**. Raw
labelling (`labelling_key="velocity_labelling_raw"`), default `OrientConfig`
otherwise.

1. **B — developmental**, per dataset × root, PCA (FA where S03 had it):
   * `{pseudotime}` and `{lineage, pseudotime}` against the chord truth:
     sign agreement, oriented fraction, also on moving axes (`|cos| ≥ 0.2`)
     and by day; for `{lineage, pseudotime}` the coverage added and the
     ranking check exactly as in S03;
   * root diagnostics: root's day-1 position (`obs["time_hours"]` is
     allowed here — it is a readout, not truth), the root percentile
     `orient` records, Spearman correlation of each root's pseudotime with
     S03's (oracle-root) pseudotime;
   * lineage–pseudotime agreement on pairs both sign (report only; run
     once with `OrientConfig(reliability_min={"velocity": 0.6,
     "pseudotime": 0.0})` to read it from `orient_meta["reliability"]`).
   * Also score the S03 oracle-root pseudotime again with the same code as
     the reference row (`root = "oracle"`).
2. **A — flow**, per dataset, PCA and FA: `{labelling}`, `{velocity}`,
   `{labelling, velocity}` with the default (reliability on), and
   `{labelling, velocity}` with `reliability_min={}` (S03's behaviour) as
   reference. Report `orient_meta["reliability"]["flow"]["velocity"]`
   (status, agreement, n_pairs), sign agreement with the expected-flow
   truth, oriented fraction, and whether the flow sign/source arrays equal
   `{labelling}`'s exactly. Also `flow_vs_dev` disagreement by day with
   `{labelling, velocity}` + `{lineage, pseudotime}` (oracle root and each
   realistic root).
3. Independence (as S03) and J hash unchanged in every call.

## Outputs

`benchmarks/synthetic_multimodal/s04/results.csv`, `summary.csv`,
`by_day.csv`, `roots.csv` (one row per dataset × root: root name,
time_hours, root percentile, Spearman vs oracle), `RESULT_S04.md` (what ran,
gates verbatim, tables, pass/fail, no interpretation); figures under
`benchmarks/figures/orient/s04/`: pseudotime agreement per root vs oracle
(per preset); flow agreement with and without the check.

## Gates (fixed now; `default`, PCA, raw labelling, seeds 0–2)

* **B1** `{pseudotime}` agreement with the chord truth over the 15
  realistic-root runs: median ≥ 0.90 and minimum ≥ 0.85.
* **B2** `{lineage, pseudotime}` oriented fraction ≥ 0.80 in every
  realistic-root run (S03 oracle: 0.83).
* **A1** velocity is `demoted` in every dataset, and `{labelling, velocity}`
  flow sign and source arrays equal `{labelling}`'s exactly.
* **A2** independence holds exactly and J is unchanged in every call.

Everything else (`stress`, `batch`, FA, by-day, moving axes, Spearman,
lineage–pseudotime agreement) is report only. A failed gate is a result.

## Stop and ask

An input checksum fails; Palantir cannot run with S03's settings or a
day-1 root (e.g. disconnected graph) — record which and stop; `orient`
refuses a root by its start-cell check (record the percentile and stop);
anything would need a truth key as an input, a refit, an edit to S03's
script or a protected path; compute over budget.
