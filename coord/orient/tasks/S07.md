# orient/S07 — Flow J, the amended guard and the lineage rule

## Goal

1. **Flow operator.** In S06 the score-matching `J` (density curvature) did
   not detect the dynamical fork (AUC 0.18), while — on one dataset — the
   Jacobian of a drift fitted on the measured labelling velocity did (AUC
   0.996). Test that across every v2 dataset, seed and embedding, and with
   scVelo's velocity as the flow input for comparison.
2. **Confirm the §16 amendment** (pseudotime minimum on the earliest
   sampling day) on **fresh** Palantir runs — it was derived from S06's.
3. **Rescore** S06 with the current layer (§16 amended, §17 lineage
   ≥ 2 cells per clone end) and diagnose why lineage agrees only ≈ 0.77
   even for well-sampled clones.

No energy-drift or labelling refit, no scVelo rerun. **Never use truth as
an input** (S06 rule and key list). Truth only for scoring, after the
orient / fit calls.

## Inputs (read, never modified)

S06's fitted units (`data/s06/`), user runs (`data/s06_user/`, manifests in
`benchmarks/synthetic_multimodal/s06/`), the v2 datasets (`MANIFEST_v2.csv`);
sha256 checks. Record versions as S06.

## Step 1 — Flow operator (`scripts/s07_flow_j.py`)

Per v2 dataset (`v2_default`, `v2_stress`, `v2_batch` × seeds 0–2, and
`v2_stationary_cycle` × 0–2) × embedding (PCA, FA):

* `MeasuredDrift(d, seed=0)` (defaults) fitted on `(z, obsm["velocity_labelling_raw"])`;
  `J_flow = jacobian_autodiff(z)`. Also with scVelo's `obsm["velocity_<method>"]`
  as the input (`J_flow_scvelo`; not for stationary_cycle).
* Per cell: `lead = max real part of the eigenvalues`, `max |imag|`.
* Truth classes from `z_true` exactly as S06 Step 4 (`saddle`,
  `committed`, `progenitor`); report per class n, median lead, fraction
  lead > 0; **AUC** of lead (saddle positive vs committed); at saddle
  cells |cos| between the eigenvector of the leading eigenvalue (real
  part) and S06's fate axis; same numbers for S06's energy `J`
  (reference). Also the 6-D truth `jacobian_state` lead per class.
* `v2_stationary_cycle`: median max |imag| of `J_flow` vs of the truth
  (`omega_state`), report only.

## Step 2 — Fresh Palantir runs for the guard (`scripts/s07_palantir_fresh.py`)

For `v2_default`, `v2_stress`, `v2_batch` × seeds 0–2, PCA only: 5 day-1
cells `np.random.default_rng(3000 + seed)` and 5 day-4 cells
`np.random.default_rng(4000 + seed)` (each `.choice(names_of_that_day, 5,
replace=False)`), Palantir with S03's settings in `default` and `strict`
mode (import S06's runner; do not edit it) → 180 runs. Store as S06
(actual start cell = pseudotime minimum). For each: `orient(...,
["pseudotime"])` with the current defaults; record accepted/refused and the
error text, Spearman with day, actual start day, and agreement with the
forward truth.

## Step 3 — Rescore and lineage diagnostic (`scripts/s07_score.py`)

* Rerun S06's scoring (import `scripts/s06_score.py`; do not edit) on all
  S06 units and S06's day-1 default-mode Palantir runs with the **current**
  layer; report every S06 number again next to its S06 value.
* Lineage diagnostic (v2_default, PCA, report only): for
  `lineage_min_cells_per_end ∈ {1, 2, 3}`, lineage agreement and oriented
  fraction against (a) the 24 h forward truth and (b) a **span-matched**
  forward truth: for each clone, `forward_developmental_truth` with
  `horizon_hours = 24 × (latest day − earliest day)` of that clone
  (truth only). Also split by whether the clone's cells have one or both
  fates (`fate_true`, scoring only).

## Outputs

`benchmarks/synthetic_multimodal/s07/{flow_j.csv,palantir_fresh.csv,results.csv,
summary.csv,lineage_diagnostic.csv,RESULT_S07.md}`; figures under
`benchmarks/figures/orient/s07/` (lead by truth class: energy J vs flow J;
guard outcomes by root day and mode).

## Gates (fixed now)

* **G1 guard (fresh runs):** every day-4-root run is refused; ≥ 90 % of
  day-1-root runs are accepted, in each mode.
* **G2 flow J:** labelling-based `J_flow` AUC (saddle vs committed) ≥ 0.90
  on every `v2_default` seed, PCA.
* **G3 developmental:** `{lineage, pseudotime}` agreement ≥ `{pseudotime}`
  agreement − 0.01 on every `v2_default` seed (PCA, raw, day-1 default
  roots).
* **G4:** independence exact and J hash unchanged in every orient call.

Everything else (scVelo-based flow J, FA, stress, batch, stationary
rotation, energy J, lineage diagnostic, all rescored S06 numbers) is report
only. A failed gate is a result.

## Run procedure

One unit per command (no long controllers — Manus's wait limit is 2 h):
each dataset × step as its own detached, timed run with a checkpoint file;
check back between units. A unit over 60 min: stop it, record, rerun once
alone; if again, stop and ask. Other jobs may share the machine.

## Stop and ask

A checksum fails; MeasuredDrift or Palantir cannot run as specified;
anything would need a truth key as an input, a refit outside this task, an
edit to S02/S03/S06 scripts or a protected path; compute over budget.
