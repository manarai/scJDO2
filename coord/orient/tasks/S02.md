# orient/S02 — End-to-end orientation tests (lineage, labelling, flags)

## Goal

Run the orientation layer end to end on the S01 synthetic data, from
count-level readouts to orientation, for the sources that need no user
run: **lineage** and **labelling**, plus the **equilibrium/stationarity
flags**. Score everything against the generator's truth. Velocity (the
user's scVelo) and pseudotime (the user's Palantir) come in S03.

**Never use truth as an input.** Inputs are only: `X`, the count layers
(`spliced`, `unspliced`, `new`, `total`), `obs["clone"]`, `obsm["clone_matrix"]`,
`obs["day"]`, `obs["pulse_hours"]`, and the embeddings `X_pca` / `X_fa`.
Every `*_true` key, `velocity_true_*`, `v_state`, `omega_state`,
`jacobian_state`, `z_true`, `fate_true` and `clone_true` is used **only for
scoring**. Do not modify the `default`, `stress` and `batch` .h5ad files
(the user runs scVelo and Palantir on them); write results to new files.

## Inputs

S01 datasets (`benchmarks/synthetic_multimodal/MANIFEST.csv`; check sha256):
`default`, `stress`, `batch`, seeds 0–2. **Regenerate** `stationary_cycle`
seeds 0–2 with the current generator (default now 5 000 founders,
≈ 2 800 cells): `python scripts/make_synthetic_multimodal.py --preset
stationary_cycle --seed <s>`, and update its MANIFEST rows.

## Steps (`scripts/orient_end_to_end.py`; seed 0 for every fit)

For each dataset and each embedding (`pca` primary, `fa` secondary):

1. **Energy drift on the embedding** — `EnergyDriftAdapter` on
   `obsm["X_<method>"]` with `EnergyDriftConfig(hidden=96, depth=3,
   n_epochs=1500, seed=0, batch_size=256, loss="esm", lr=5e-4, beta=1.0,
   esm_laplacian="exact")`. Store `uns["scjdo2"]["J"] =
   jacobian_autodiff(z)`, `obsm["X_drift_v"] = velocity(z)` (the score),
   `obs["energy"] = energy(z)`. `symmetry_check` max ≤ 1e-4, else stop.
2. **Labelling velocity** (the labelling source's input):
   * Fit `LabelledRateModel` on `(new, total, z = X_<method>, t_c =
     pulse_hours)` with its defaults (record epochs and held-out NLL).
   * Per cell × gene, transcription from new RNA:
     `α̂ = γ · new / (1 − exp(−γ · t_c))` (γ from the fit); gene-space
     velocity `v_g = α̂ − γ · total` (per hour).
   * Map `v_g` into the embedding with the same chain rule as
     `true_velocity_in_embedding(..., at="observed")` (library-size
     normalisation, `log1p`, the embedding's `linear_map`), treating `v_g`
     as the velocity of the counts the embedding was fitted on. → the raw
     labelled latent velocity.
   * Smooth it with `MeasuredDrift` (defaults, seed 0) fitted on
     `(z, raw)`; `obsm["velocity_labelling"] = MeasuredDrift.velocity(z)`.
     Keep the raw version as `obsm["velocity_labelling_raw"]`.
3. **Orientation** — `scjdo2.orient.orient(adata, sources, f"X_{method}")`
   with default `OrientConfig`, for `["lineage"]`, `["labelling"]`,
   `["lineage","labelling"]`; and once more with the raw labelling
   velocity (`labelling_key="velocity_labelling_raw"`) as a sensitivity.
4. **Truth** — for each dataset, `true_velocity_in_embedding(a, method,
   at="expected")`; truth sign per (cell, axis) =
   `sign(v_true_expected · u)` on the axes returned by `orient`.
5. **Scores** (every rate over (cell, axis) pairs that pass the gap rule
   and have support; also report the same restricted to axes the true
   velocity moves along, `|cos(v_true, u)| ≥ 0.2`):
   * sign agreement with truth, oriented-cell fraction, per source set;
   * `["lineage","labelling"]`: conflict rate, and sign agreement where
     the two sources conflict (which one the truth sides with);
   * rotation share — report only: per cell `‖omega‖_F / ‖J_v‖_F`, where
     `J_v` is the local velocity Jacobian the labelling source regressed
     (`omega` is its antisymmetric part); median per preset, and in
     `default` per day. The truth rotation lives in the 6-D state and has
     no exact image in a 20-D embedding, so no error against truth is
     computed; the expectation is a larger share in `stationary_cycle`
     and in day-1 (cycling) cells than in day-4 cells;
   * flags: fraction `equilibrium` / `non_equilibrium` /
     `not_identified`, and `stationary` / `non_stationary`, per preset.
   * J hash unchanged in every `orient` call.
6. **Outputs**: `benchmarks/synthetic_multimodal/s02/results.csv` (one row
   per dataset × embedding × source set × labelling variant), `summary.csv`
   (per preset × embedding × source set, mean and min over seeds),
   `RESULT_S02.md` (what ran, the gates verbatim, the tables, pass/fail by
   gate, no interpretation), figures under
   `benchmarks/figures/orient/s02/` (sign agreement per preset and source
   set; oriented fraction; flags by preset). Fitted objects stay local,
   gitignored, under `benchmarks/synthetic_multimodal/data/s02/`.

## Gates (fixed now, before any S02 run; `pca`, labelling smoothed)

On the **default** preset, all three seeds:
* `["lineage"]` sign agreement ≥ 0.90; oriented fraction ≥ 0.3.
* `["labelling"]` sign agreement ≥ 0.85; oriented fraction ≥ 0.3.
* `["lineage","labelling"]` sign agreement ≥ 0.90; oriented fraction
  ≥ 0.5.
* J hash unchanged in every call.

On **stationary_cycle**, all three seeds: `non_equilibrium` on ≥ 0.8 of
cells with an identified equilibrium flag (rotating flow is not a scaled
score).

Everything else (`stress`, `batch`, `fa`, raw labelling, omega,
stationarity, the moving-axes restriction) is **report only**. A gate that
fails is a result: report it with `status: done`.

## Stop and ask

An input checksum fails; a symmetry check exceeds 1e-4; anything would
need a truth key as an input, a change to a protected path, or a change to
the S01 user-facing files; compute over budget.
