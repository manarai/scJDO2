# orient/S03 — Every source combination, end to end

## Goal

Run scVelo (velocity source, flow group) and Palantir (pseudotime source,
developmental group) with the settings fixed below — the user handed these
runs to this task — and add them to S02's lineage and labelling,
and score every combination against the right truth. Uses the two-output
layer (`docs/ORIENTATION_SPEC.md` §12). Gates are fixed below, before the
scVelo and Palantir outputs exist.

**Never use truth as an input** (same rule and key list as S02). scVelo
reads only `spliced`, `unspliced` and the stored embeddings; Palantir reads
only `X_pca` and its start cell. **One stated exception:** the start cell
`uns["suggested_start_cell"]` was chosen by the generator from the truth
(earliest-day cell nearest the progenitor state) — an expert-chosen root,
i.e. a best case for Palantir. Report this with the pseudotime results.

## Inputs

1. **S01 datasets** `default`, `stress`, `batch` × seeds 0–2 (check sha256
   against `MANIFEST.csv`); they are read, never modified.
2. **S02 fitted units** (`benchmarks/synthetic_multimodal/data/s02/
   <preset>_s<seed>_<method>.h5ad`; check against S02's metrics): the
   energy-drift operator `uns["scjdo2"]["J"]`, `obsm["X_drift_v"]`,
   `obs["energy"]`, `obsm["velocity_labelling_raw"]`,
   `obsm["velocity_labelling"]`. **No refitting.**
3. `stationary_cycle` (S02 units) for flags only (no user runs).

## Step 0 — scVelo and Palantir (`scripts/run_scvelo_palantir_s03.py`)

Install `scvelo` and `palantir` into your `.venv` and record both versions
(and scanpy's). Use the installed scVelo (0.3.4 is fine). Any other
scVelo function named below that is missing in it: stop and ask — do not
substitute. If either cannot be installed or run with these settings,
stop and ask. For each of the 9 datasets, on a **copy**:

* **scVelo** — `X = spliced`; keep `obsm["X_pca"]` and `obsm["X_fa"]` from
  the S01 file. `scv.pp.filter_genes(min_shared_counts=20)` (genes only;
  never filter or reorder cells), `scv.pp.normalize_per_cell`,
  `scanpy.pp.log1p` (on `X` only — the same operation as `scv.pp.log1p`, which scVelo 0.3.x removed; amended in review); `sc.pp.neighbors(use_rep="X_pca", n_neighbors=30,
  random_state=0)`; `scv.pp.moments` on those neighbours (it must not
  recompute PCA). **Primary: dynamical** — `scv.tl.recover_dynamics`,
  `scv.tl.velocity(mode="dynamical")`; **sensitivity: stochastic** —
  `scv.tl.velocity(mode="stochastic")`, **optional** (amended in review,
  Revision 1): try it once per dataset; if it raises, record the error
  text in the report and continue without the stochastic keys. It is
  report only; no gate uses it. For each mode,
  `scv.tl.velocity_graph`, then `scv.tl.velocity_embedding(basis="pca")`
  and `(basis="fa")` → `obsm["velocity_pca"]`, `obsm["velocity_fa"]`
  (dynamical) and `obsm["velocity_pca_stochastic"]`,
  `obsm["velocity_fa_stochastic"]`. Check after: `X_pca` unchanged, cell
  order unchanged.
* **Palantir** — diffusion maps on `X_pca` with 10 components, multiscale
  space, `run_palantir` with `early_cell = uns["suggested_start_cell"]`,
  `num_waypoints = 500`, `knn = 30`, `seed = 0` (use the installed
  version's AnnData API; record which). Store
  `obs["palantir_pseudotime"]`, `uns["palantir_start_cell"]`.
* Write `benchmarks/synthetic_multimodal/data/user/<preset>_s<seed>_user.h5ad`
  holding the S01 file plus **only** those added keys; record a manifest of
  these files (path, sha256, keys, versions, wall time) in the report.

## Steps (`scripts/orient_end_to_end_s03.py`; replaces the S02 script, which used the single-sign API)

For each dataset × embedding (`pca` primary, `fa` where the user file has
`velocity_fa`):

1. Build one AnnData from the S02 unit, adding from the user file only
   `obsm["velocity_<method>"]`, `obs["palantir_pseudotime"]`,
   `uns["palantir_start_cell"]`.
2. **Labelling variant:** primary = raw (`labelling_key =
   "velocity_labelling_raw"`; S02 showed smoothing lowers sign agreement);
   smoothed reported as sensitivity.
3. **Combinations** (`orient`, default `OrientConfig` otherwise):
   flow `{labelling}`, `{velocity}`, `{labelling, velocity}`; dev
   `{lineage}`, `{pseudotime}`, `{lineage, pseudotime}`; and once all four
   together (for the cross-group report and the independence check).
4. **Truths** (scoring only):
   * flow → `true_velocity_in_embedding(a, method, at="expected")`;
   * dev → **chord truth**: noise-free embedded positions
     `z_exp = (log1p(E · T / ΣE) − mean) @ linear_map` with
     `E = s_true · capture_factor · batch_gene_effects[batch_day]` and the
     embedding's stored `T`, `mean`, `linear_map`; per **true** clone,
     latest-day centroid minus earliest-day centroid of `z_exp`, assigned
     to every cell of the clone (clones on one day only: no dev truth).
5. **Scores** (over supported, gap-passing (cell, axis) pairs; each also
   restricted to axes the relevant truth moves along, `|cos| ≥ 0.2`; each
   also **by day**):
   * per combination: sign agreement with its truth, oriented fraction;
   * **what each source adds**: for the two-source combination of each
     group, (a) cells oriented only because the lower-ranked source is
     present (coverage added) and the agreement on those cells, (b) the
     agreement on cells where the higher-ranked source decides;
   * **ranking check**: where the two sources of a group conflict, the
     fraction where the truth sides with the higher-ranked source;
   * **cross-group**: `flow_vs_dev` disagreement rate, by day;
   * **independence**: flow outputs identical with and without dev
     sources, and vice versa (must hold exactly);
   * flags on `stationary_cycle` and per preset; J hash unchanged in every
     call.
6. **Outputs**: `benchmarks/synthetic_multimodal/s03/results.csv`,
   `summary.csv`, `by_day.csv`, `RESULT_S03.md` (what ran, the gates
   verbatim, tables, pass/fail by gate, no interpretation), figures under
   `benchmarks/figures/orient/s03/` (agreement by combination and preset;
   coverage added; by day; conflicts and which source the truth sides
   with).

## Gates (fixed now; `default` preset, PCA, raw labelling, all three seeds)

* **Flow**
  * `{velocity}` (scVelo, dynamical) sign agreement ≥ 0.75; oriented
    fraction ≥ 0.3. (Stochastic mode is report only.)
  * `{labelling, velocity}` oriented fraction ≥ that of `{labelling}`;
    agreement on cells labelling decides is unchanged from `{labelling}`
    (exact, by construction).
  * Ranking: where labelling and velocity conflict, truth sides with
    labelling ≥ 0.60.
* **Developmental**
  * `{lineage}` agreement with the chord truth ≥ 0.95.
  * `{lineage, pseudotime}` oriented fraction ≥ 0.90.
  * Ranking: where lineage and pseudotime conflict, truth sides with
    lineage ≥ 0.80.
* **Independence** holds exactly in every run; J unchanged in every call.

`{pseudotime}` alone is **report only** (accepted limitation, §13), as are
`stress`, `batch`, FA, smoothed labelling, the moving-axes and by-day
breakdowns, and flags beyond S02's. A failed gate is a result.
