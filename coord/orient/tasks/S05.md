# orient/S05 — Synthetic generator v2

## Why

An audit (`coord/orient/reviews/audit_2026-10-17/README.md`) found the S01
data computed correctly but unrealistic in three ways that bias results:

1. **Splicing:** unspliced is 2.1 % of counts (real ~15–30 %; 94.7 % zeros)
   and no gene switches or reaches a steady state, so phase-portrait rate
   estimation (scVelo) reverses direction even though the direction is
   recoverable with the true rates.
2. **Noise:** counts are pure Poisson; real UMI counts are overdispersed.
3. **Lineage:** 20 % of all living cells are sampled per day, so 77 % of
   detected clones span ≥ 2 days; real lineage experiments sample far less.

Build **v2 presets** that fix these, keep **v1 bit-for-bit unchanged**, and
prove with oracle checks that each readout carries recoverable signal
**before** any method is run on it. Do not run the orientation layer.
Every value below is fixed; if one cannot be implemented as written, stop
and ask.

## 1. Presets

Add `v2_default`, `v2_stress`, `v2_batch`, `v2_stationary_cycle` to
`make_multimodal`. Each is its v1 namesake (same latent dynamics §1 of S01,
same stress/batch/stationary knobs) **plus** §2–§5 below. v1 presets and
their code path must produce **identical arrays** to the S01 files
(MANIFEST.csv) — test this.

## 2. Splicing (v2 only)

* `β_g ~ LogNormal(log 0.6, 0.5)` h⁻¹ (v1: log 3); `γ_g` unchanged.
* Unspliced capture `η_u = 0.6` (v1: 0.3), as a config field (not the
  module constant, which v1 keeps).
* `v2_stress` keeps the β doubling on 20 % of genes half-way.

## 3. Switching genes (v2 only)

30 % of genes (240 of 800, chosen with the gene rng), in three equal types
(80 each). Their transcription replaces `exp(W_g·z + b_g)` with
`α_g(z) = α_lo + (α_hi − α_lo) · h_g(z)`, `α_lo = exp(b_g − 1.5)`,
`α_hi = exp(b_g + 1.5)`, logistic `σ(x) = 1/(1+e^{−x})`, width `w = 0.05`:

* `on` (induced with progression): `h = σ((z1 − θ_g)/w)`, `θ_g ~ U(0.3, 1.6)`;
* `on_off` (transient): `h = σ((z1 − θ_g)/w) · (1 − σ((z1 − θ_g − Δ_g)/w))`,
  `θ_g ~ U(0.3, 1.0)`, `Δ_g ~ U(0.4, 0.8)`;
* `fate` (one fate only): `h = σ(s_g z0 / w) · σ((z1 − 1.2)/w)`,
  `s_g = ±1` with equal probability.

The other 70 % keep the log-linear `α`. Store `var["gene_kind"]`
(`linear`/`on`/`on_off`/`fate`), `var["theta"]`, `var["delta"]`,
`var["fate_sign"]` (NaN where unused). Founders start at steady state for
their own `α`, as in v1.

## 4. Overdispersion (v2 only)

At collection, per cell × gene, a multiplier `m ~ Gamma(shape θ_g,
scale 1/θ_g)` (mean 1), `θ_g ~ LogNormal(log 20, 0.5)`, **shared** by the
unspliced and spliced draws: `spliced ~ Poisson(m · capture · s)`,
`unspliced ~ Poisson(m · capture · η_u · u)`; total and new as in v1 (new
split from total by the true new fraction, then efficiency). `m` is
measurement noise: the truth (`s_true`, `ds_dt_true`, the expected-count
truth of `true_velocity_in_embedding`) does **not** include it. Store
`var["nb_theta"]`; do not store `m`.

## 5. Lineage sampling (v2 only)

`n_founders = 5000`, `f_sample = 0.01` (`v2_stationary_cycle`: 5000
founders, `f_sample = 0.20`, one day, as v1). Expected ≈ 140 / 400 / 1 100
/ 3 100 cells on days 1–4 (≈ 4 800), most clones seen on one day only.

**Implementation:** the population reaches ≈ 3 × 10⁵ living cells; do not
integrate gene pools for every living cell. The latent SDE, divisions and
sampling consume the rng exactly as now (gene pools consume none), so:
simulate `z` for the whole population, keep each cell's `z` path since its
birth (or enough to rebuild it deterministically), and integrate `u, s,
u_new, s_new` (and `s_prev`) **only along the ancestral paths of collected
cells**, with the same `_rna_step`. Peak memory ≤ 12 GB, ≤ 20 min per
dataset; otherwise stop and ask.

**Run procedure (amended in review, Revision 1).** Claude measured the
committed code (`fc30fb0`) on this machine: `v2_stress` seed 2 in 3.4 min,
3.7 GB peak, with another project's job running alongside. So:
* generate **one dataset at a time** (no parallel generation), each in its
  own process, timed with `/usr/bin/time -l`; record wall time and peak RSS;
* if a dataset exceeds **30 min**, stop it, record its timing, environment
  (python and numpy versions, `os.cpu_count()`, load average) and the last
  stage reached, and rerun it **once** alone; if the rerun also exceeds
  30 min, stop and ask;
* other jobs may share the machine; do not stop them;
* the five completed v2 files may be kept if regenerating each one's
  `obs`/`layers` hash matches (determinism); else regenerate.

## 6. Tests (`tests/test_synthetic_multimodal.py`; all must pass)

* **v1 unchanged:** for `default` seed 0, every layer/obsm/obs array equals
  the stored S01 file exactly.
* **Lazy equals eager:** on a small v2 config (`n_founders = 60`,
  `f_sample = 0.2`, `poisson = False`), pools from the ancestral-path
  integration equal a full-population integration (rtol 1e-5).
* S01 tests 1–6 for `v2_default` (determinism; kinetics finite difference;
  truth mapping median cos ≥ 0.99 PCA and FA; lineage label ↔ founder,
  detected fraction `p_barcode ± 0.03`; labelling analytic; time and
  dynamics) — test 4's "≥ 50 % multi-day" is **replaced** by: ≥ 50
  detected multi-day clones.
* Size: `v2_default` total collected 3 800–5 800.
* Switch genes have steady states: for `on` genes, over cells with
  `z1 > θ_g + 0.5`, the fraction with `|s_true − α_hi/γ| / (α_hi/γ) < 0.1`
  is ≥ 0.5 for ≥ 50 % of `on` genes.

## 7. Oracle checks (`scripts/audit_synthetic.py`; port of the audit scripts)

Per dataset (v2 presets × seeds 0–2, and v1 `default` seeds 0–2 as
reference), PCA:

* realism: UMI/cell, genes/cell, spliced zeros, **unspliced share of
  counts**, unspliced zeros, var/mean after library normalisation,
  new/total, barcode fraction, clone size, fraction and number of detected
  clones spanning ≥ 2 days, R² of each `z_true` dim from `X_pca`;
* **O1** splicing with the **true** β, γ on kNN-30 moments in `X_pca`
  (library-normalised counts, as `fixtest.py`), mapped by the same chain
  rule as the truth: median cosine with `velocity_true_expected_pca`;
* **O2** labelling with the true γ on raw counts (as `embed_oracle.py`);
* **O3** splicing with γ **fitted** per gene from the moments by the
  steady-state extreme-quantile fit (5 %, as `fixtest.py`) — report only;
* **O4** one scVelo dynamical run on `v2_default` seed 0 with exactly
  S03's settings (`scripts/run_scvelo_palantir_s03.py`'s scVelo part;
  import it, do not edit it): median cosine of `velocity_pca` with the
  expected truth, overall and by day — report only.

## Gates (fixed now; `v2_default`, seeds 0–2)

* All §6 tests pass; `tests/test_orient.py` and `tests/test_smoke.py` pass.
* Unspliced share of counts in [0.10, 0.30].
* **O1** median cosine ≥ 0.40; **O2** median cosine ≥ 0.30.

O3, O4, the other presets and all realism numbers are report only. A
failed gate is a result — report it; do not tune any value to pass.
