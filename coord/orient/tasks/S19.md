# orient/S19 — dyngen datasets (Part 1: generation + realism)

Agent **C** (Codex), folder `~/Documents/scJDO2-manus-C`, rules in
`coord/PROJECT.md` and `.sandbox/SANDBOX.md` (3 threads, 14 GB). Part 2
(repeating the headline flow-J / score-J results on these data) is a later
task, after S14/S15 — **do not run any scJDO2 operator here**.

## Environment (authorised; inside your folder only)

R 4.6 is at `/opt/homebrew/bin/Rscript`. Install **dyngen** (CRAN, record
version) and its dependencies into a **private library**
`.sandbox/Rlib` (`R_LIBS_USER=.sandbox/Rlib`; never install into the system
or user R library). If installation fails, stop and ask.

## Datasets (`scripts/s19_dyngen.R`, `scripts/s19_export.py`)

Three backbones × seeds 0–2, each with dyngen's documented defaults except
as stated: `backbone_bifurcating()` (fork), `backbone_cycle()` (rotation),
`backbone_linear()` (no fork, null). Target ≈ 5 000 cells and ≈ 1 000 genes
(`num_cells = 5000`, `num_tfs`/`num_targets`/`num_hks` set so the total is
≈ 1 000 — record them). Use dyngen's **synchronised** experiment with **3
sampling time points** (analogous to days 2/4/6) so a time course exists;
keep its kinetics, simulation time and the produced spliced / unspliced
counts. If a run exceeds 60 min or 14 GB, reduce `num_simulations` once
(record) and retry; if it still fails, stop and ask.

## Export (truth kept separate from inputs)

Per dataset an `.h5ad` under `benchmarks/dyngen/data/` (gitignored) with:
inputs — raw `spliced`, `unspliced` (layers), `X` = spliced,
`obs["day"]` (time point 1–3); **truth** (scoring only, prefixed `truth_`) —
simulation time, milestone percentages / backbone position, the cell's
branch, dyngen's ground-truth RNA velocity if produced, the GRN. Write
`benchmarks/dyngen/MANIFEST.csv` (path, sha256, cells, genes, settings).

## Realism (`scripts/s19_realism.py`)

Run S08's statistics and comparison **by importing**
`scripts/s08_reference_stats.py` / `s08_compare.py` (do not edit) on the
nine dyngen datasets, next to generator v3 (`v3_default`, rows already in
`benchmarks/real_reference/`) and the real references. Report the match
rate and the within-real-range table per statistic; no gates.
