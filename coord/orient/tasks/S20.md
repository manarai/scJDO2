# orient/S20 — Scaling the time-course flow operator

Agent **C** (Codex), folder `~/Documents/scJDO2-manus-C`, `.sandbox/` rules
(3 threads, 14 GB per process). Uses the **S10/S11 reference flow-J
configuration** (so it does not depend on S14): PCA-30 transport space of
log-normalised counts (2 000 HVGs), balanced entropic OT with
ε = 0.05 × median squared distance between consecutive days, barycentric
velocity / Δt (48 h), `MeasuredDrift(30, seed=0)` defaults, Jacobian by
autodiff. Only the **OT solver** changes.

## Data (read in place, never modify; sha256 as S08)

`~/Documents/scJDO2/benchmarks/data/larry/larry_inVitro_raw.h5ad` (raw `X`,
`obs["Time point"]` 2 / 4 / 6; 130 887 cells). Read backed / in chunks.
Embedding fitted on **all** cells (HVGs `seurat_v3` on counts, PCA via a
randomised solver, `random_state=0`).

## Solvers (`scripts/s20_scaling.py`)

* **dense:** POT `ot.sinkhorn` (S11's path) — only where it fits in memory.
* **low-rank:** `moscot` low-rank OT (`.venv-baselines` already has moscot
  0.5.2; use its documented low-rank option, rank r ∈ {50, 200}) **or** POT
  `ot.lowrank_sinkhorn` if moscot cannot run — record which.
* **mini-batch:** POT dense Sinkhorn on random batches of 4 000 source ×
  4 000 target cells (`default_rng(0)`), barycentres averaged over 10
  batches per source cell (each source cell in ≥ 1 batch; record coverage).

## Steps

1. **Agreement with dense** on subsamples where dense fits: n per day ∈
   {2 000, 4 000, 8 000} (`default_rng(0)`, nested). For each scalable
   solver: per-cell velocity cosine with dense (median), and the flow-J
   λ₁ Spearman over cells between dense- and scalable-velocity operators.
2. **Scaling curves:** for n per day ∈ {2 000, 4 000, 8 000, 16 000, full},
   each solver (dense until it would exceed 14 GB — estimate first, never
   start a run predicted to exceed): wall time, CPU time, peak RSS (`/usr/bin/time
   -l`); same for the MeasuredDrift fit and the Jacobian.
3. **Full LARRY:** the best scalable solver on all cells → velocity, flow J,
   λ₁ by cell type and day (report); compare with S11's 4 000-per-day result
   (λ₁ by cell type, rank correlation).

## Gates (fixed now)

* **G1** at n = 4 000 per day: one scalable solver reaches median velocity
  cosine ≥ 0.90 with dense **and** flow-J λ₁ Spearman ≥ 0.80.
* **G2** that solver completes **full LARRY** (velocity + flow J) with every
  unit ≤ 14 GB peak RSS and ≤ 2 h wall.

Everything else report only.
