# orient/S09 — Generator v3, calibrated to real data

## Goal

Add `v3_*` presets to `make_multimodal` whose readouts match the real-data
statistics of S08, by **fitting a small set of generator knobs to those
statistics** (never to any orientation, operator or oracle result), then
re-measure every S08 statistic with S08's own code. v1 and v2 stay
bit-for-bit unchanged. Do not run the orientation layer.

## Design changes (v3 only; everything not listed is as v2)

1. **More genes, realistic levels.** `n_genes = 4000`. Transcription
   intercepts `b_g ~ N(μ_b, σ_b)` (knobs). Capture as v2.
2. **Gene programmes.** Each gene has one kind: `constant` (α independent
   of `z`: `α = exp(b_g)`), `linear` (v2 log-linear), `on`, `on_off`, `fate`
   (v2 switching kinds, same shapes). Shares: `f_constant` (knob), switching
   share `f_switch` (knob, split equally over on / on_off / fate), rest
   linear.
3. **More latent programmes.** Add `n_prog` (knob, 0–8) extra latent
   dimensions, each an Ornstein–Uhlenbeck process `dy = −y/τ dt + s dW`
   with `τ ~ U(6, 48)` h and stationary sd 1, independent of development
   (e.g. cell size, stress, metabolic state). Linear / constant genes load
   on them as on the core dims (`W` sparse, 1–3 loadings per gene from all
   `6 + n_prog` dims). These dims are **nuisance**: the dynamics truth
   (`v_state`, `jacobian_state`, fate, forward truth) is unchanged on the
   six core dims; store `obsm["z_true"]` with all dims and
   `uns["synthetic_multimodal"]["core_dims"] = [0..5]`.
4. **Noise.** Gamma–Poisson multiplier as v2 with `θ_g ~ LogNormal(log θ₀, 0.5)`,
   `θ₀` a knob.
5. **Kinetics.** `γ_g ~ LogNormal(log γ₀, σ_γ)` (knobs); `β_g ~ LogNormal(log β₀, 0.5)`
   and `η_u` (knobs).
6. **Labelling design as scNT-seq haematopoiesis:** pulses of 3 h and 5 h,
   each on half of the cells of every sampling day (seeded); ε as v2.
7. **Lineage and time design as LARRY in vitro:** sampling at 48, 96, 144 h
   (days 2, 4, 6); `p_barcode`, `n_founders` and `f_sample` knobs (one
   `f_sample` for all days, as v2). Destructive sampling and lazy RNA as v2.

Knobs: `μ_b, σ_b, f_constant, f_switch, n_prog, θ₀, γ₀, σ_γ, β₀, η_u,
p_barcode, n_founders, f_sample` — 13, each with the bounds in the table
below. Nothing else may be changed.

## Calibration (`scripts/s09_calibrate.py`)

**Targets** (S08 statistics; real value or min–max range from
`benchmarks/real_reference/compare.csv`; a statistic counts as met when the
synthetic value — scalar or distribution median, as in S08's
`within_real_range` — lies in the target interval):

| knob(s) | bounds | statistic(s) | target |
|---|---|---|---|
| μ_b, σ_b | μ_b ∈ [−4, 1], σ_b ∈ [0.5, 2.5] | C2 genes detected / cell, C3 HVG log mean, C5 zero fraction, C1 library | real min–max |
| f_constant | [0, 0.6] | S3 `steady` share | real min–max (0.12–0.46) |
| f_switch | [0, 0.6] | S3 `cycle`, `induction` shares; S4 recovered fraction | real min–max |
| n_prog | {0, …, 8} | C7 participation ratio, C6 HVG pair correlation | real min–max |
| θ₀ | [1, 50] | C4 overdispersion | real min–max |
| γ₀, σ_γ | γ₀ ∈ [0.05, 0.5], σ_γ ∈ [0.3, 1.5] | L2 half-life median and IQR, L1 new/total median and IQR | scNT-seq haematopoiesis (L2), both scNT-seq (L1) |
| β₀, η_u | β₀ ∈ [0.1, 3], η_u ∈ [0.2, 1] | S1 unspliced share, S2 | **0.30** ± 0.05 for S1 (central in the real 0.08–0.50) |
| p_barcode, n_founders, f_sample | [0.2, 0.8], [200, 5000], [0.005, 0.3] | G1, G2 median, G3, G4 | LARRY ± fixed tolerance (S08) |

**Procedure.** Objective = number of unmet targets, ties broken by the sum
of normalised distances to the target intervals (0 inside). Search: a
seeded Latin-hypercube of 64 knob vectors on reduced-size runs (same
design, `n_founders` scaled so ≈ 1 500 cells; lineage knobs evaluated at
full size), then coordinate refinement (each knob, 5 values, 2 passes) from
the best. The statistics are computed with **S08's functions, imported, not
copied**. Record every evaluated vector and its statistics
(`calibration_log.csv`). **The calibration must not read any orientation,
operator, oracle or truth-based quantity** (assert: the objective function
receives only the S08 statistic table).

Fix the best vector as the `v3_default` constants. `v3_stress`,
`v3_batch`: v3_default plus v2's stress / batch modifications;
`v3_stationary_cycle`: v3 genes and noise with v2's stationary-cycle
design.

## Tests (`tests/test_synthetic_multimodal.py`)

v1 and v2 arrays unchanged (as S05); lazy = eager for a small v3 config; S01
tests 1–6 for `v3_default` (truth mapping, kinetics, labelling analytic,
lineage label ↔ founder); nuisance dims do not enter `v_state` /
`jacobian_state` (they equal v2's functions of the core dims).

## Final measurement (`scripts/s09_measure.py`)

Generate `v3_default`, `v3_stress`, `v3_batch` × seeds 0–2 and
`v3_stationary_cycle` × 0–2 (one dataset per command, timed); run S08's
statistics and comparison on them (import S08's scripts) next to v1/v2;
run S05's oracles O1–O4 on `v3_default` (import S05's audit).

## Outputs

`scjdo2/data/synthetic_multimodal.py` (v3), `scripts/make_synthetic_multimodal.py`
(v3 presets) → `benchmarks/synthetic_multimodal/data/v3/` (gitignored),
`benchmarks/synthetic_multimodal/MANIFEST_v3.csv`,
`benchmarks/synthetic_multimodal/v3_calibration/{calibration_log.csv,
knobs.json, compare_v3.csv, oracles_v3.csv, RESULT_S09.md}`, figures under
`benchmarks/figures/real_reference/v3/` (each S08 panel with v3 added), and
a v3 section in `docs/SYNTHETIC_MULTIMODAL.md`.

## Gates (fixed now; `v3_default`, seeds 0–2)

* Tests pass; v1/v2 unchanged.
* **Realism:** each of C2, C3, C4, C5, C7 participation ratio, S1, S3
  steady share, S4 recovered fraction, L1 median, L2 median, G1, G2
  median, G3 meets its target on every seed (13 statistics).
* **Signal still present:** O1 (true splicing rates on moments) ≥ 0.30 and
  O2 (true labelling γ) ≥ 0.20 on every seed — lower than S05's gates
  because real-like data is sparser; report the values.

Everything else is report only. A failed gate is a result; do not widen
a bound or add a knob to pass.

**Budget amended in review (Revision 1): 24 CPU-hours** (was 16; the
schedule projected 16.02). Resume from the checkpointed log; do not rerun
completed candidates.

## Executor and parallel runs (amended 2026-10-19, Revision 2)

From Revision 2 the executor is a **local Claude agent** (same protocol as
`coord/MANUS.md`, same folder, branch, contract and checker). The
one-unit-at-a-time rule existed for Manus's platform limits; it is
replaced by: **up to 6 calibration evaluations may run concurrently**, each
its own process with `OMP_NUM_THREADS=2`, `MKL_NUM_THREADS=2`,
`OPENBLAS_NUM_THREADS=2`, and scVelo `n_jobs=1` where the code allows it
(do not edit S08's protected functions; if one hard-codes `n_jobs`, keep it
and lower the concurrency so total threads ≤ 12). Each evaluation still
writes its own checkpoint; the LHS / refinement order and seeds are
unchanged, so results do not depend on concurrency. Resume from the
committed checkpoints; never rerun a completed candidate. Final datasets
may also be generated concurrently (≤ 4 at once).

## Dataset size and budget (amended 2026-10-19, Revision 3)

* **Size (amended, Revision 4: was 4 000–6 000):** full-size `v3_*` datasets
  (except `v3_stationary_cycle`) must have **4 000–15 000 collected cells** (real references: 2–6 k, LARRY
  larger). After the refinement, keep every knob of the selected vector
  except `n_founders`, and set `n_founders` to the value (within its
  bounds) whose full-size genealogy collects closest to 5 000 cells
  (lineage-only runs, as in calibration). Re-check G1–G3 at that size and
  report them; if a lineage target is lost by the rescaling, report it —
  do not re-tune.
* **Block refinement (Revision 4).** The count-of-unmet objective let the
  selected vector miss S1 by a factor > 20. Starting from the selected
  vector `refine_p2_n_founders_3`, refine the knob blocks that act on
  separate statistics, in this order, each accepting a change only if the
  number of unmet targets (all 13) does not increase:
  1. **Splicing** — `β₀ × η_u` on a 5 × 5 grid within bounds (log-spaced
     for β₀); **S1 must be met** — among grid points meeting S1, take the
     one with fewest unmet, ties by distance. If none meets S1, report.
  2. **Turnover** — `γ₀ × σ_γ`, 5 × 5 grid; prefer points meeting L1 and L2.
  3. **Lineage and size** — full-size **lineage-only** runs: `n_founders ∈
     {200, 300, 500, 800, 1200}` × `f_sample` 8 log-spaced values in its
     bounds (`p_barcode` as selected); among points with 4 000–15 000 cells,
     fewest unmet among G1–G3, ties by distance.
  4. **Expression** — `μ_b × σ_b`, 5 × 5 grid; prefer points meeting C2 and
     C5 without losing C3.
  Reduced-size runs as in calibration except block 3. Every evaluation is
  logged as before. Then fix the vector and run the final measurement. Any
  target still unmet is reported with its closest value; no further search.
* **Re-ranking (Revision 5; no new calibration runs).** Two flaws of the
  task's design (Claude's): target bands for statistics with a single real
  reference were far narrower than real-data variation (L1 ±0.005, L2
  ±4 %, G2 ±5 %), and the count objective treats a 20-fold miss like a
  hair-thin one. So: (1) for every target with **one** real reference (L1
  uses both scNT-seq values; L2, G1–G3 one), the band becomes S08's fixed
  tolerance — value × [1/1.25, 1.25] (KS-type targets unchanged); targets
  with several real references keep the real min–max; (2) **S1 is
  required**; (3) re-rank **all** evaluated vectors (LHS, refinement,
  blocks; reduced-size statistics as logged): S1 met first, then fewest
  unmet, then distance. Apply block 3's lineage choice to the winner
  (full-size lineage-only runs, 4 000–15 000 cells; same grid), then the
  final measurement. Report the re-ranked top 5 with their unmet targets.
* **Memory (Revision 5):** stop condition raised to **24 GB** peak RSS per
  process; generate final datasets **one at a time**.
* **Budget: 40 CPU-hours**, measured over whole process trees
  (`/usr/bin/time -l`), including the prior run's estimated 1.09 h of
  unmetered worker CPU.
* **Unreachable targets:** if a target stays unmet for every evaluated
  vector and its knobs are at their bounds, report it as unreachable in
  this design (e.g. C2 genes detected per cell with 4 000 genes); do not
  widen bounds or add knobs.

## Run procedure

One evaluation batch or one dataset per detached, timed command with a
checkpoint (Manus's 2-h wait limit); a unit over 60 min: stop, record,
rerun once alone; if again, stop and ask.

## Stop and ask

A v1/v2 array changes; a design change cannot be implemented as written;
the calibration would need a knob or bound not listed; memory > 24 GB (Revision 5);
compute over budget.
