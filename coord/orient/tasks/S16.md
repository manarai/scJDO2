# orient/S16 — Head-to-head benchmark

**Issue only after S14 (and S15) are accepted.**

## Methods (each with its native input, and with a common input where possible)

| method | native input | common input |
|---|---|---|
| scJDO2 flow J* (S14 selected) | time course (OT) | — |
| scJDO2 score J | positions | — |
| dynamo | labelling (one-shot) and scVelo velocity → SparseVFC → Jacobian | OT velocity of S14 |
| spliceJAC | spliced/unspliced, Leiden clusters on expression PCA → per-cluster Jacobian | — |
| scJDO v1 | pseudotime-conditioned drift (`compare/run_v1.py`; install via `scripts/install_v1_compare.sh` — stop and ask if it fails) | Palantir strict pseudotime |

## Data / truth

`v3_transition` s2–s4 and `v3_default` s2–s3 (S14 test seeds; never tuned on),
full; `v3_stationary_cycle` s0–2 (rotation). All Jacobians compared in the
same PCA-k* space (methods working in gene space: project by the PCA map;
spliceJAC: cluster Jacobian assigned to its cells).

## Metrics (truth, scoring only)

Per-cell `J_ref` error (S14 definition); fork AUC (saddle vs committed);
regime recovery NMI via S15's archetype step applied to each method's
operator; λ₁ sign accuracy by regime; rotation on the cycle (max |imag| vs
truth); runtime and memory.

All report only — a benchmark table, no gates. Each method's settings are
its documented defaults; state every choice. Figures: metric × method bars
