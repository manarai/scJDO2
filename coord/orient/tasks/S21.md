## Part A — regenerate bifurcating datasets (fixes S19)

S19's three `bifurcating` datasets contain **one branch only** (s0, s1: all
post-branch cells on D; s2: all on C). Regenerate with
`scripts/s19_dyngen.R` / `s19_export.py` unchanged except via their existing
arguments: `backbone_bifurcating()`, `--num-simulations 64`, other S19
settings identical. Generate seeds **10, 11, 12, …** in order (write to
`benchmarks/dyngen/data/bifurcating_v2_s<seed>.h5ad`). **Accept** a seed when
the minority branch holds **≥ 25 %** of post-branch cells (truth used only
for this acceptance, recorded); keep the **first three** accepted seeds.
Record every seed tried, its branch counts and runtime. Stop after seed 21
(12 tries) or 8 CPU-h for Part A, whichever is first, and report if fewer
than three are accepted (then continue Part B with those accepted and
report). A single run > 2 h or 14 GB: stop it and report. Append rows to
`benchmarks/dyngen/MANIFEST.csv`; do not delete the S19 files.

## Part B — operators (inputs only)

Datasets: the accepted `bifurcating_v2` seeds, `cycle_s0–2`, `linear_s0–2`
(S19). Per dataset, full (no subsampling):

1. Normalise spliced counts to the median library size, `log1p`, all 1 000
   genes; PCA-15 (`random_state=0`), raw coordinates (`z`).
2. **Flow J:** S14 reference configuration, imported, not copied —
   `scripts/s14_choose_k.py::REFERENCE` with `space = "raw"` (as in
   `scripts/s14_test.py::config_for("reference")`), via
   `s14_choose_k.fit_flow(d, config)` with `d = {"z", "day", "hours"}`,
   `hours = 48 × (day − 1)` (dyngen has no clock; record it — flow J is
   compared by sign/rank only). Drift seeds 0, 1, 2 (separate fits).
3. **Score J:** S10's score settings, refit in the same PCA-15 (record the
   function and settings used).

## Part C — scoring (truth read here only)

Truth regions from `truth_backbone_from/to/percentage`:
* bifurcating: **fork** = cells on the edge into the branch milestone
  (`sB → sBmid`) plus cells on `sBmid → sC/sD` with percentage < 0.15;
  **committed** = cells on the terminal edges (`sC → sEndC`, `sD → sEndD`)
  with percentage ≥ 0.5; **early** = `sA → sB`.
* `J_ref` (report only): dyngen `truth_rna_velocity` projected with the same
  normalisation + PCA loadings → `scripts/s12_step0.py::jref(z, v_true)`.

Per dataset and operator: fork AUC (λ₁ fork vs committed, as S14);
fraction Re λ₁ > 0 per region; rotation index max|Im λ| / max|λ| per cell;
Step-0 diagnostics vs `J_ref` (‖J‖/‖J_ref‖, optimal scalar c* and its
relative error, per-cell cosine, Spearman λ₁(J) vs λ₁(J_ref)).

## Gates (fixed now)

* **F1** flow-J fork AUC ≥ 0.85 on every accepted `bifurcating_v2` dataset
  and every drift seed.
* **F2** median flow-J rotation index on `cycle_sN` > that on `linear_sN`,
  for N = 0, 1, 2 and every drift seed.

Score-J AUC and rotation, J_ref diagnostics: report only.
