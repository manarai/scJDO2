# atlas/R02 — Do motifs recur across hematopoiesis datasets? (DRAFT)

**Draft. Finalised from R01's results before it's issued**, including
the reference dataset, `K`, and every threshold, which will be fixed in
the Gate before any number is computed.

## Outline

1. **Harmonised lineage map** (written by Claude before issue): each
   dataset's labels → {stem/progenitor, MEP/erythroid, megakaryocyte,
   GMP/monocyte, neutrophil, basophil, DC, lymphoid}. Mouse vs human only
   matters for genes, not for descriptors.
2. **Reference.** The R01 descriptor space of one usable dataset
   (largest, most stable). Motif centres = KMeans with R01's `K`.
3. **Projection.** Every other dataset's R01 s = 0 descriptors are
   assigned to the nearest reference centre (no refit), plus a distance
   to that centre. Cells farther than the reference's own 95th percentile
   are labelled "unmatched".
4. **Recurrence vs dataset-shuffle null.** Per motif, the occupancy in
   each dataset against a null that permutes dataset labels within
   harmonised lineage, so the null keeps lineage composition. A motif
   **recurs** if it's enriched in ≥ 2 datasets.
5. **Lineage concordance.** For each recurrent motif, the harmonised
   lineage where it's most enriched, compared across datasets (for
   example, does the fork-like motif sit at the MEP/GMP split in every
   dataset?). Agreement vs a label-permutation null.
6. **Batch control.** Dataset-vs-dataset motif occupancy distances,
   compared with R01's batch-half and random-half distances. A motif
   "recurs" no more than batch would allow if the cross-dataset distance
   is within the batch-half distance.
7. **Leave-one-dataset-out.** Rebuild the reference from each other
   usable dataset; does the recurrent set change?

Gene-level motif concordance (driver vectors; needs mouse–human
orthologs) is a later task.
