# hlca/HX03 — Fixed-axis curvature statistic (EXPLORATORY)

**Exploratory.** This statistic was designed by Claude *after* H04 and
HX02, so nothing here can change the frozen H04 outcome or RESULT.md
§1–§10. State "EXPLORATORY — statistic designed after the frozen
result" in the first line of the report and of `RESULT_HX03.md`.

## Background

HX02 showed the frozen isotropy statistic (log-eigenvalue ratios after
re-matching) has almost no power for single-axis softening in human
lung, because the soft eigenvalue is often near zero or positive.
`compare.softaxis_curvature_trend` tracks the curvature along the
**fixed** young soft axis, `κ_d = uᵀ Op_d u / median|λ(Op_d)|`, and
tests its slope on age with donor-level age permutations. It is
invariant to uniform scaling. Claude's validation on 6 types is in
`benchmarks/aging_hlca/softaxis_design/claude_validation_6types.csv`.

## Inputs (check sha256 against the H03/HX02 reports)

`benchmarks/aging_hlca/data/h03_primary_drift.h5ad`,
`h03_secondary_drift.h5ad`; `benchmarks/aging_hlca/tests_primary.csv`
(the 13 types).

## Steps (`scripts/hlca_softaxis.py`; seed 0)

1. **Power grid (all 13 types).** Exactly the HX02 protocol (same
   injections, donor operators, reference operator, 50 replicates of
   80 % of donors, replicate seeds `crc32(f"{type}|rep{r}")`), with the
   test `softaxis_curvature_trend(..., n_perm=200, seed=0)`; pass =
   `passes`. Injections: no injection; single-axis `F ∈ {1.25, 1.5, 2,
   3, 5, 8}`; uniform `F ∈ {1.5, 2, 3}` (false-pass check).
   → `benchmarks/aging_hlca/softaxis/power_grid.csv`
   (`ann_level_3, kind, size, power`) and `mde.csv`
   (`ann_level_3, mde_single_axis_F, ref_soft_eigenvalue,
   max_uniform_pass_rate`; MDE = smallest F with power ≥ 0.80,
   `> max` if none).
2. **Gate on the grid before step 3:** for each type,
   `max_uniform_pass_rate ≤ 0.20`. Types failing it are listed and
   **excluded from step 3** (their statistic is not specific there).
3. **Application to the real data** (no injection), full donor sets,
   `n_perm = 1000`, `seed = 0`, for the types passing step 2:
   * `primary` — H04's primary space and donors;
   * `a_within_study` — `strata` = `study_or_dataset`;
   * `e_secondary_space` — the HLCA 30-D embedding drift.
   → `benchmarks/aging_hlca/softaxis/real.csv`
   (`analysis, ann_level_3, n_donors, slope, p, passes,
   ref_soft_eigenvalue, mde_single_axis_F`).
4. **Reading rule (fixed before step 3; apply mechanically):**
   * a type shows **soft-axis change with age** in an analysis if
     `p ≤ 0.05`; it shows it **after correction** if `p ≤ 0.05 / n`
     (`n` = number of types in step 3);
   * a type is **robust** if it shows the change after correction in
     `primary` **and** at p ≤ 0.05 in both `a_within_study` and
     `e_secondary_space`, with the same sign of slope;
   * report the sign: slope > 0 means `κ` moves toward zero or positive
     (the soft axis flattens relative to the rest), slope < 0 the
     opposite.
   Write the counts and the list of robust types to
   `softaxis/summary.csv` and the report metrics.
5. Figures (`benchmarks/figures/aging_hlca/softaxis/`, PDF + PNG, footer
   "EXPLORATORY · hlca/HX03 · statistic designed after the frozen
   result"): power curves (one line per type, 0.80 marked, old HX02
   isotropy curve dashed for comparison); per-type `κ_d` against age for
   the primary analysis, coloured by study, slope line, `p` in the title.
6. `benchmarks/aging_hlca/softaxis/RESULT_HX03.md`: first line as above,
   what ran, the reading rule verbatim, tables, the mechanical counts.
   No other interpretation.
