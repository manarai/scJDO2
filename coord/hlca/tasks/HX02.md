# hlca/HX02 — Power analysis on the real donor data (EXPLORATORY)

**Exploratory.** Nothing here changes the frozen H04 outcome or
RESULT.md §1–§10. State "EXPLORATORY" in the first line of the report.
No model is fitted: synthetic aging effects of known size are injected
into the **real** H03 drift-subsample cells, and the **frozen** H04 tests
are rerun on them.

## Question

H04 found no aging change. How large would a change have had to be for
H04 to find it? Per eligible type, find the **minimum detectable effect
(MDE)** at 80 % power for three kinds of aging, each matching one frozen
test.

## Inputs (check sha256 against the H03/H04 reports)

`benchmarks/aging_hlca/data/h03_primary_drift.h5ad`
(`X_scVI_primary`, per-cell `J_latent`, donor metadata);
`benchmarks/aging_hlca/tests_primary.csv` (the 13 types).

## Definitions (fixed before the run)

For each type: `ref` = the H04 reference operator (pooled cells of donors
aged < 45, `compare.centroid_operator`, 30 cells); `u` = its soft axis
(eigenvector of its largest eigenvalue); `σ_u` = standard deviation of
the young pooled cells' projections on `u`. Age is mapped to
`t = (age − 10) / 66` (0 at 10 years, 1 at 76). Injections apply to
**every cell** of the type, using that cell's donor age:

1. **Single-axis softening** (target: `isotropy_trend`), fold `F`:
   `J' = J + (F^(−t) − 1) · (uᵀ J u) · u uᵀ` — the curvature along `u`
   is divided by `F^t`; other directions unchanged.
   `F ∈ {1.25, 1.5, 2, 3, 5, 8}`.
2. **Uniform softening** (target: `stiffness_trend`), fold `F`:
   `J' = F^(−t) · J`. `F ∈ {1.1, 1.25, 1.5, 2, 3}`.
3. **Drift along the young soft axis** (target: `anticipation_trend`),
   size `D` (in units of `σ_u` over the age range):
   `z' = z + D · σ_u · t · u`. `D ∈ {0.5, 1, 2, 4, 8, 16}`.

Plus a **null row** (no injection, `F = 1`, `D = 0`) for the baseline
pass rate.

Grids were widened after a one-type probe by Claude (Macrophages, all
donors): uniform 1.25× already passes; single-axis needs ~3×; drift
was not detected at 2 σ.

## Steps (`scripts/hlca_power.py`; seed 0 throughout)

1. For each type, injection kind and size (and the null row): build the
   donor operators **exactly as H04** (`compare.donor_operator`,
   `n_common=50`, `n_draws=100`, 30 cells, seed
   `crc32(f"{type}|{donor}")`) from the injected cells; the reference
   operator from the **uninjected** young cells.
2. **Replicates:** 50 random subsamples of 80 % of the type's
   contributing donors, without replacement
   (`np.random.default_rng(crc32(f"{type}|rep{r}"))`). On each, run the
   target test with H04's settings except `n_perm = 200`
   (`isotropy_trend` for kind 1, `stiffness_trend` for kind 2,
   `anticipation_trend` for kind 3). **Power** = fraction of the 50
   replicates that pass (`passes` for 1 and 3; for 2, a pass is
   `stiffness_trend.passes` **and** a negative slope).
3. **MDE** per type and kind = the smallest grid size with power ≥ 0.80;
   `"> max"` if none reaches it.
4. Outputs:
   * `benchmarks/aging_hlca/power/power_grid.csv`
     (`ann_level_3, kind, size, power, n_donors_per_replicate`);
   * `benchmarks/aging_hlca/power/mde.csv`
     (`ann_level_3, mde_single_axis_F, mde_uniform_F, mde_drift_D,
     null_pass_rate_iso, null_pass_rate_stiff, null_pass_rate_ant`);
   * figures `benchmarks/figures/aging_hlca/power/` (PDF + PNG; footer
     "EXPLORATORY · hlca/HX02 · not part of the frozen outcome"):
     power curves per kind (one line per type, 0.80 marked); an MDE
     heatmap (types × kinds);
   * `benchmarks/aging_hlca/power/RESULT_HX02.md`: what ran, the
     definitions verbatim, the MDE table, and these sentences filled in
     mechanically: "Across the 13 types, the median MDE was ×<F> for
     single-axis softening, ×<F> for uniform softening, and <D> σ for
     drift along the soft axis, over ages 10–76." No other
     interpretation.

## Gate

None: every MDE is a result. Report the null-row pass rates; if any
exceeds 0.20, say so (it would mean the 80 % subsampling inflates false
passes, which Claude will weigh).
