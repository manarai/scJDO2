# hlca/H01 — HLCA data, reference model and age inventory

## Goal

Get the HLCA core data and the HLCA scArches reference model onto disk,
prove that scArches query mapping runs in our environment, and produce
the metadata inventory Claude needs to write the human
pre-registration. **No model is fitted on human data for analysis and
no aging statistic is computed in this task**: only counts, metadata
and a timing smoke test.

## Steps

1. **Environment.** Reuse `.venv` in your folder (from aging/A01) or
   create it; add `scarches` and `scvi-tools` versions compatible with
   the HLCA reference model. Run `python -m pytest
   tests/test_compare_aging.py -q`. Append an `## hlca` section to
   `benchmarks/aging_hlca/ENV.md` with all versions.
2. **Data** — write `scripts/fetch_hlca.py` (idempotent, records
   source URLs, versions, sha256):
   * HLCA **core** with raw counts and full donor/sample metadata.
     Prefer the CZ CELLxGENE Discover release (via `cellxgene_census`,
     pin and record the census version, or the dataset's h5ad from the
     HLCA collection); record the dataset ID.
   * HLCA **reference model** for scArches (`HLCA_reference_model.zip`)
     and the reference embedding, from Zenodo record 7599104 (if the
     record or file names differ, use the latest record linked from the
     HLCA GitHub/README and record exactly what was used).
   Save under `benchmarks/aging_hlca/data/` (gitignored large files).
3. **Inventory** — write `scripts/inventory_hlca.py`; commit these
   tables under `benchmarks/aging_hlca/inventory/`:
   * `obs_columns.csv` — every `.obs` column: name, dtype, n unique,
     n missing, 5 example values. Identify the age field(s) (e.g.
     `age_or_mean_of_age_range`, `development_stage`) and say which
     you used and why.
   * `donors.csv` — one row per donor: donor id, age (numeric, years;
     how ranges were converted), sex, smoking status, BMI, study /
     dataset, sampling site(s) (`anatomical_region_ccf_score` or
     tissue), assay, n cells.
   * `age_by_study.csv` — donors per study in age bins
     `<30, 30–44, 45–59, ≥60`, and for each study min/median/max age.
   * `celltype_by_agebin.csv` — cells and donors per
     `(annotation_level, cell_type, age_bin)` for annotation levels
     `ann_level_3`, `ann_level_4` and the cellxgene `cell_type` (use
     whichever of these exist; record the names).
   * `confounds.csv` — for donors: cross-tabs of age bin × smoking,
     age bin × sex, age bin × sampling site, age bin × assay, and the
     Spearman correlation of age with each numeric covariate.
   * `within_study_contrast.csv` — studies that contain donors in both
     `<45` and `≥60`, with donor counts per side and the cell types
     with ≥ 200 cells on both sides within that study.
4. **scArches smoke test** — `scripts/hlca_scarches_smoke.py`:
   following the scArches HLCA tutorial, map a 5 000-cell subsample
   (seed 0) of HLCA core cells from **one** study as a query onto the
   reference model by scArches surgery (scANVI), 20 epochs. Record:
   success, API path used, wall time, peak RAM, time per 10 000 cells
   extrapolated, and the max absolute change of the frozen reference
   weights (must be 0). This is a plumbing test, not an analysis;
   discard the embedding.
5. **Report.** In Observations, state plainly which designs the
   inventory supports: (a) young-only reference + old mapped in, as in
   mouse; (b) within-study young-versus-old contrasts; (c) age as a
   continuous covariate. Do not choose; Claude decides in H02.

## Gate

* `test_compare_aging.py` passes; scArches smoke test succeeds with
  reference weight change 0. Otherwise blocked.
* Inventory tables complete. A missing age field is blocked.

## Stop and ask

Download > 30 GB total; the reference model cannot be loaded with any
scvi-tools/scarches version you can install; HLCA core lacks donor age
or donor IDs.
