# hlca/H03 — Preprocessing, shared spaces, drift (PREREG_aging_hlca §1–§3)

## Goal

Build both shared spaces for the 106 aged HLCA core donors and fit the
energy drift on the drift subsample, exactly as `PREREG_aging_hlca.md`
§1–§3 state. **No test or statistic of §5 is computed here** (that is
H04); this task ends with per-cell Jacobians, basin calls and the
eligibility table.

## Inputs (on disk in your folder; check sha256 against `coord/hlca/reports/H01.json`)

`benchmarks/aging_hlca/data/hlca_core_raw_counts.h5ad`,
`hlca_core_full_metadata.h5ad`, `HLCA_full_v1.1_emb.h5ad`,
`HLCA_reference_model/`.

## Binding clarifications (Claude)

* **"Rare"** (§1): its cells stay in HVG selection and scVI training
  (they are cells of the donors); the type is excluded only from
  eligibility and all analysis.
* **Donor without a numeric age** (§1): excluded from everything,
  including scVI.
* **Seeds:** `crc32` means `zlib.crc32(f"{donor}|{type}".encode())`
  (as the mouse arm).
* **Memory:** load raw counts sparse; if any step would exceed ~28 GB
  RAM, stop and ask rather than subsample differently.

## Steps

1. `scripts/hlca_preprocess.py` — §1–§2: filter donors, counts layer,
   HVGs (`seurat_v3`, 2 000, `batch_key="study_or_dataset"`, `span=1.0`)
   on all cells of the 106 donors; the **drift subsample** (≤ 60 cells
   per donor × `ann_level_3`, seed as above). Commit
   `benchmarks/aging_hlca/drift_subsample_cells.csv.gz`
   (cell_id, donor_id, ann_level_3, age, study_or_dataset,
   anatomical_region_ccf_score, smoking_status) and
   `benchmarks/aging_hlca/qc/preprocess_summary.csv`.
2. `scripts/hlca_fit_scvi.py` — §3 primary: young-only reference
   (donors < 45, all cells), scArches query (donors ≥ 45) with
   `load_query_data(..., accelerator="cpu", device="auto")` and
   `weight_decay=0`, all settings as §3. **Save per-epoch training
   history** (ELBO train and validation) to
   `benchmarks/aging_hlca/qc/scvi_history_{reference,query}.csv`.
   Frozen check on latent-encoder parameters **and** BatchNorm buffers:
   exactly 0, else stop.
3. `scripts/hlca_fit_drift.py` — §3 drift on the drift subsample, for
   **(a) the primary shared latent** (15-D) and **(b) the secondary
   published HLCA embedding** (`HLCA_full_v1.1_emb.h5ad`, matched by
   cell ID; record its dimension). Locked settings; per-cell `J`; basin
   calls; `sym_max ≤ 1e-4` else stop.
4. `scripts/hlca_eligibility.py` — §4 eligibility on the drift
   subsample (`n_common = 50`; ≥ 20 donors with ≥ 5 < 45 and ≥ 5 ≥ 60),
   for the primary analysis and for the §7(b–d) subsets
   (Banovich_Kropski_2020 only, parenchyma only, never-smokers only).
   → `benchmarks/aging_hlca/eligibility.csv`
   (`analysis, ann_level_3, n_donors, n_lt45, n_ge60, eligible`).
5. RESULT.md (`benchmarks/aging_hlca/RESULT.md`): §1 Data, §2
   Preprocessing, §3 Shared spaces, as executed.

## Gate

* Frozen check exactly 0; `sym_max ≤ 1e-4` for both drift fits.
* Expected from the metadata (Claude's feasibility check): **13**
  primary-eligible types (AT2, Basal, Dendritic cells, EC arterial,
  EC capillary, EC venous, Fibroblasts, Innate lymphoid cell NK,
  Macrophages, Monocytes, Multiciliated lineage, Secretory, T cell
  lineage); parenchyma 12; never-smokers 6. A different count is not a
  stop, but list every difference and its cause.

## Stop and ask

Memory over ~28 GB; scVI or drift diverges; frozen check ≠ 0;
`sym_max > 1e-4`; compute would exceed the budget.
