# hlca/H04 — Frozen tests and outcome

## Goal

Run `PREREG_aging_hlca.md` §4–§7 once, exactly as written, and record
the §6 outcome. Nothing is refitted; everything comes from the H03
drift outputs. Every outcome is a result.

## Inputs (on disk in your folder; check sha256 against `coord/hlca/reports/H03.json`)

`benchmarks/aging_hlca/data/h03_primary_drift.h5ad` (primary latent,
per-cell `J`, basin calls, donor metadata) and
`h03_secondary_drift.h5ad` (HLCA 30-D embedding);
`benchmarks/aging_hlca/eligibility.csv`.

## Steps (`scripts/hlca_tests.py`; one run, seed 0)

1. **Donor and reference operators (§4)** per eligible type, per
   analysis: donors with ≥ 50 cells of the type contribute;
   `compare.donor_operator(z, J, n_common=50, n_draws=100,
   n_cells_centroid=30, seed=zlib.crc32(f"{type}|{donor}".encode()))`;
   reference operator = `compare.centroid_operator` (30 cells) on the
   pooled cells of that type from donors aged < 45. Write
   `benchmarks/aging_hlca/donor_operators.csv` (analysis, type, donor,
   age, study_or_dataset, log_median_abs_lambda, lead_eig, anisotropy,
   centroid as `;`-joined values).
2. **Primary tests (§5)** on the 13 primary-eligible types, primary
   space, all contributing donors, `n_perm=1000`, `seed=0`,
   `strata=None`: `isotropy_trend`, `anticipation_trend`,
   `stiffness_trend`. →
   `benchmarks/aging_hlca/tests_primary.csv` with columns
   `ann_level_3, n_donors, n_lt45, n_ge60, iso_S, iso_q95, iso_p,
   iso_pass, median_beta, ant_stat, ant_q95, ant_p, ant_pass,
   stiff_slope, stiff_p, stiff_class` (`loss` = slope < 0 and p ≤ 0.05;
   `gain` = slope > 0 and p ≤ 0.05; else `none`).
3. **Outcome (§6):** majorities over the 13 types; the header and the
   stiffness qualifier, verbatim, in `benchmarks/aging_hlca/RESULT.md`
   §5 as `**<header>** <qualifier>`. Run
   `python scripts/hlca_outcome_check.py` before reporting; it must pass.
4. **Sensitivity (§7)**, same tests and settings, reported in
   `benchmarks/aging_hlca/tests_sensitivity.csv` (column `analysis`):
   * `a_within_study`: primary types and space, `strata` = each donor's
     `study_or_dataset`;
   * `b_banovich`: Banovich_Kropski_2020 donors only (its 2 eligible
     types);
   * `c_parenchyma`: cells with `anatomical_region_ccf_score == 0.97`
     only (12 types);
   * `d_never_smokers`: never-smoker donors only (6 types);
   * `e_secondary_space`: the 13 types in the HLCA 30-D embedding drift;
   * `f_two_group`: donors < 45 and ≥ 60 only, with `ages` replaced by
     the indicator `age ≥ 60` (0/1); 13 types.
   For b–d, the reference operator uses that subset's < 45 donors; a
   type that loses eligibility in a subset is listed, not rescued.
   Sensitivity results never change §6.
5. **RESULT.md** (`benchmarks/aging_hlca/RESULT.md`): add §4 Eligible
   types and operators, §5 Outcome (header + qualifier verbatim), §6
   Per-type table, §7 Sensitivity table, each "as executed". No
   interpretation beyond the rule; Claude interprets in review.

## Gate

None to pass. `scripts/hlca_outcome_check.py` must agree with
RESULT.md.

## Stop and ask

An input checksum fails; an eligible type has fewer than 20 contributing
donors in the primary analysis (would contradict H03); compute over
budget.
