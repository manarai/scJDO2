# hlca/H02 — Pre-registration (Claude, from the H01 inventory)

Written after H01's metadata inventory and **before any fit on human
data**. Presented to the user for approval before it is committed.

## Decisions to freeze in `PREREG_aging_hlca.md`

1. **Age groups.** Young and old definitions (e.g. `< 45` vs `≥ 60`
   years, excluding the middle), chosen from `age_by_study.csv` so both
   groups have enough donors; or age continuous, if bins are too thin.
2. **Design for the shared space** (from what H01 shows is feasible):
   * **primary** — mirror mouse: a young-only scVI/scANVI reference
     trained on HLCA core young donors, old donors mapped in by scArches
     with frozen weights; standalone fits per age as the correction
     control;
   * **secondary** — the published HLCA scANVI reference (all ages)
     with the HLCA embedding as the shared space; reported beside the
     primary, never instead of it.
3. **Confounds.** Batch key (study / sample), and how study is handled:
   restrict to studies with within-study age contrast if
   `within_study_contrast.csv` allows, else study as batch with a
   leave-one-study-out sensitivity check. Smoking, sex and sampling
   site: stratify, restrict or report, decided from `confounds.csv`.
4. **Cell types.** Annotation level, and the inclusion gate (≥ 200
   cells in both age groups after donor-balanced downsampling; donor
   floor per side).
5. **Tests and outcome rule.** `PREREG_aging_basins.md` §4b, §5, §6
   unchanged; majority over eligible non-artifact human types.
6. **Mouse–human comparison.** Type matching table (mouse TMS type ↔
   HLCA type) frozen in advance; the comparison statistic (agreement of
   `iso_pass`/`ant_pass`, and cosine of aging vectors in operator
   coordinates) and its null.
