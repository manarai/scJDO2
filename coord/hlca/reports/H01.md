# hlca/H01 — HLCA data, reference model and age inventory

## Summary

H01 completed the prescribed local HLCA data and reference-model plumbing without fitting a human analysis model or computing an aging statistic.
The canonical core is the CZI full-metadata H5AD for Census dataset `066943a2-fdac-4b29-b348-40cede398e4e` (584,944 cells; 107 donors; raw counts at `adata.raw.X`).
The local Zenodo 7599104 model and embedding loaded through scArches surgery on the fixed 5,000-cell seed-0 smoke query.
The smoke run completed 20 CPU epochs with frozen-reference maximum absolute weight change **0.0**.
The canonical age field is `age_or_mean_of_age_range`; 106 of 107 donors have parseable numeric ages (10.0–76.0 years).
The inventory supports all three candidate H02 designs—young-reference mapping, within-study contrast, and continuous age—but chooses none.

## What ran

1. `python -m pytest tests/test_compare_aging.py -q` — 9 passed.
2. `python scripts/fetch_hlca.py --phase reference` — retrieved `HLCA_reference_model.zip` and `HLCA_full_v1.1_emb.h5ad` from Zenodo 7599104 using resumable verified ranges.
3. `python scripts/fetch_hlca.py --phase core` — pinned Census release 2025-11-08, selected dataset `066943a2-fdac-4b29-b348-40cede398e4e`, and retrieved the official CZI full-metadata H5AD; the raw matrix is at `adata.raw.X`.
4. `python scripts/inventory_hlca.py` — generated the six required inventory tables and the machine-readable field-selection record.
5. `python scripts/hlca_scarches_smoke.py --seed 0 --n-cells 5000 --epochs 20` — mapped a deterministic query from `Banovich_Kropski_2020` through `sca.models.SCANVI.prepare_query_anndata` and `sca.models.SCANVI.load_query_data`; the query embedding was discarded.

## Deviations

- The first Census-export AnnData exposed generic CELLxGENE fields only. The task permits the HLCA collection H5AD, so the canonical inventory instead uses the official CZI H5AD URL in the same pinned Census catalogue; it supplies full donor/sample metadata plus `adata.raw.X`.
- Zenodo API transfer stalled for the large reference embedding. The final retrieval used resumable 8 MiB ranges from the same record and exact asset; it did not change the data or analysis specification.
- One donor has no parseable age. The donor remains in `donors.csv`; age-stratified summaries use the 106 donors with stated numeric ages.

## Observations

- The data retain all requested covariates: sex, smoking status, BMI, anatomical-region score, assay, dataset, and `ann_level_3`, `ann_level_4`, and CELLxGENE `cell_type` annotations.
- Six source studies contain both `<45` and `≥60` donors. These form a possible within-study comparison set; the full per-cell-type eligibility listing is in `within_study_contrast.csv`.
- The smoke test matched 99.6% of reference variables and did not change any of 858,156 frozen reference parameters.
- The metadata supports (a) a young-only reference with older cells mapped in, (b) within-study young-versus-old contrasts, and (c) continuous-age modeling. No H01 result selects a design.

## Suggestions

- H02 should pre-register one primary human design before any human fit, including the handling of the donor without a parseable age.
- H02 should name planned adjustment or stratification for study, smoking, anatomical region, assay, sex, and BMI; `confounds.csv` records their age-bin distributions and BMI age correlation.
- H02 could pre-specify a within-study sensitivity analysis in the six qualifying studies to limit study-level age confounding.
