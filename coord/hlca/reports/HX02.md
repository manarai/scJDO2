# EXPLORATORY — hlca/HX02 power analysis

## Summary
**EXPLORATORY.** HX02 injected fixed synthetic effects into real H03 primary
Drift-subsample cells; no model was fitted and no frozen H04 output changed.
The final 260-row grid used 50 fixed 80%-donor subsamples and 200 permutations
per target test. The median MDE is **>8×** for single-axis softening (12/13
beyond grid), **×1.5** for uniform softening, and **2 σ** for soft-axis drift.
The maximum null-row pass rate is **0.96** (T cell lineage stiffness).

## What ran
1. Required `tests/test_compare_aging.py` and `tests/test_compare_hlca.py` — 17 passed before the grid and again in final validation.
2. SHA-256 validation of H03 `h03_primary_drift.h5ad` and H04 `tests_primary.csv` against their committed reports — passed.
3. `python scripts/hlca_power.py --seed 0 --dry-run` — verified 260 rows, 11,034 donor-operator builds, 13,000 replicate tests, and 200 permutations/test.
4. `python scripts/hlca_power.py --seed 0` — final deterministic grid. Earlier two executions used the same seed/data/settings solely to correct right-censor median reporting and the required CSV schema.
5. Re-derived all MDEs from `power_grid.csv`, directly checked all three injection equations on a real AT2 cell, inspected all four figure families, and verified every PDF footer.

## Deviations
EXPLORATORY task. The first successful execution exposed a reporting-only
right-censor median error and an extra helper column in `power_grid.csv`. The
code was corrected and rerun twice under the same frozen seed, injection grid,
operator construction, donor draws, and tests. The final CSV has exactly the
five specified columns; no model or frozen H04 file changed.

## Observations
- Only AT2 reached 80% power for single-axis softening (F=3); the other 12 types remained beyond F=8.
- Uniform-softening MDEs are F=1.1–3 for all 13 types; drift MDEs are D=0.5–4 σ for all 13.
- Null pass rates exceed 0.20 for EC capillary anticipation (0.34), EC venous stiffness (0.24), Monocytes stiffness (0.22), and T cell lineage stiffness (0.96).

## Suggestions
- If approved, characterize the fixed cosine-matching statistic's non-monotone single-axis response curves before extending the F grid.
- If approved, test how donor composition and age/study balance influence the elevated null-row rates, without altering H04.
