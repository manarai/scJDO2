## Summary
HX03 is exploratory and does not modify the frozen H04 outcome. The fixed-axis curvature grid used 13 primary types, 50 deterministic 80%-donor replicates/type-condition, and 200 age permutations/replicate. All 13 types passed the uniform-scaling specificity gate and entered the full-donor application (1,000 permutations/analysis).

1. `tests/test_compare_aging.py` and `tests/test_compare_hlca.py`: **20 passed** before data use.
2. SHA-256 checks for both H03 drift inputs, the H04 primary test table carried by HX02 provenance, and the HX02 isotropy comparison grid: **passed**.
3. `python scripts/hlca_softaxis.py --seed 0 --dry-run`: verified 130 power rows, fixed donor subsets, and 200/1,000 power/real-data permutation settings.
4. `python scripts/hlca_softaxis.py --seed 0`: regenerated the complete final seed-zero tables and 14 figure families. The first otherwise-identical run exposed only a plotting column-access error; see **Deviations**.
5. Re-derived every MDE and uniform gate from the final CSVs, directly checked the fixed-axis injection equation on an AT2 cell, checked report/result wording, and visually reviewed the power curves plus representative per-type κ figures.

## Mechanical reading rule
- A type shows **soft-axis change with age** in an analysis if `p ≤ 0.05`; it shows it **after correction** if `p ≤ 0.05 / n` (`n` = number of types in step 3).
- A type is **robust** if it shows the change after correction in `primary` **and** at p ≤ 0.05 in both `a_within_study` and `e_secondary_space`, with the same sign of slope.
- Slope > 0 means `κ` moves toward zero or positive (the soft axis flattens relative to the rest), slope < 0 the opposite.

Applied mechanically, no primary or within-study row has p≤0.05 and no type is robust. The single secondary nominal result is Macrophages (`slope=-0.0023724784507874208`, `p=0.026973026973026972`); it does not meet the robust rule.
